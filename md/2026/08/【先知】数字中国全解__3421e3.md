## 1.Coordinates

### 题目描述

给了一个异常的 `ResNet50` 模型权重文件 `secret.pth` 。题面提示：

-   敌方把机密信息藏在了神经网络参数里；
-   数据分析师发现了一个出现频率异常的“常数”；
-   这个常数可能是解开坐标系统的钥匙。

目标是从权重文件中恢复出 flag。

`.pth` 文件通常可以直接用 `torch.load()` 读取。先看看里面是什么：

```python
import torch
state_dict = torch.load('secret.pth', map_location='cpu')
print(type(state_dict), len(state_dict))
```

输出显示它是一个 `OrderedDict` ，一共 320 个参数张量，符合 ResNet50 的权重结构。

```python
import numpy as np

target = np.float32(0.5201314091682434)

hits = []
for k, v in state_dict.items():
    arr = v.detach().cpu().numpy()
    cnt = int(np.count_nonzero(arr == target))
    if cnt:
        hits.append((k, arr.shape, cnt))

print(hits)
print('total =', sum(x[2] for x in hits))
```

可以发现这个值一共出现了 **145 次**，并且主要分布在下面这些层里：

```latex
('conv1.weight', (64, 3, 7, 7), 46)
('bn1.bias', (64,), 1)
('layer1.0.conv1.weight', (64, 64, 1, 1), 17)
('layer1.0.bn1.running_var', (64,), 1)
('layer1.0.conv2.weight', (64, 64, 3, 3), 78)
('layer3.1.conv1.weight', (256, 1024, 1, 1), 1)
('fc.weight', (1000, 2048), 1)
```

这就很不正常了。正常训练出来的浮点权重，不太可能在多个层里精确地反复出现同一个 32 位浮点值，还出现这么多次。

说明这个常数大概率就是隐写“标记位”。

### 二、把所有参数展平成一条“全局坐标轴”

把所有层的参数按 `state_dict` 的顺序依次拼接成一条长数组，记录这个异常常数出现的 **全局位置**。

```python
import numpy as np

idxs = []
base = 0

for k, v in state_dict.items():
    arr = v.detach().cpu().numpy().ravel()
    pos = np.flatnonzero(arr == target)
    for p in pos:
        idxs.append(base + int(p))
    base += arr.size

print('count =', len(idxs))
print('first 20 =', idxs[:20])
```

```latex
600, 700, 1000, 1100, 1400, 1500, 1700, 1800, ...
```

规律：

绝大多数位置都是 **100 的倍数**；

只有两个位置不是 100 的倍数：

3105212（mod 100 = 12）

24938036（mod 100 = 36）

也就是说，145 个命中位置里， **143 个都严格落在 100 的倍数上**。

这基本可以推断出：

出题人是每隔 100 个参数放一个“采样点”，如果该位置写入异常常数，就表示这一位是 `1` 。

### 三、把 100 间隔位置还原成 bitstream

把所有命中的全局位置映射成 bit 位：

若某个异常常数出现在全局位置 `i` ，并且 `i % 100 == 0` ；

那么它对应的 bit 下标就是 `i // 100` ；

该 bit 记为 `1` ；

没被命中的位置记为 `0` 。

```python
ones = sorted(set(i // 100 for i in idxs if i % 100 == 0))
mx = max(ones)

bits = ['0'] * (mx + 1)
for p in ones:
    bits[p] = '1'

bitstr = ''.join(bits)
print('bit length =', len(bitstr))
```

这样我们就得到了一个 01 串。

### 关键判断的补全

真正需要确认的不是某个数值看起来特殊，而是它在序列化后的参数空间中是否具有可编码性。 `float32` 精确相等值跨卷积核、BN 状态和全连接层重复出现，且命中位置呈稳定步长，已经排除了普通梯度更新带来的随机重复。

全局偏移依赖 `state_dict` 的迭代顺序。每个张量的扁平下标加上前序张量元素总数，才构成作者写入时使用的单一坐标系。两个非整百命中点不参与位流恢复；过滤后只需枚举 8 种字节起点和两种位序， `flag{` 即成为明确判据。

```python
base = 0
ones = set()
for tensor in state_dict.values():
    values = tensor.detach().cpu().numpy().ravel()
    for index in np.flatnonzero(values == TARGET):
        point = base + int(index)
        if point % 100 == 0:
            ones.add(point // 100)
    base += values.size
stream = ''.join('1' if i in ones else '0' for i in range(max(ones) + 1))
for offset in range(8):
    data = stream[offset:]
    data = data[:len(data) // 8 * 8]
    plain = bytes(int(data[i:i + 8], 2) for i in range(0, len(data), 8))
    if b'flag{' in plain:
        print(offset, plain)
```

无需执行 ResNet50 前向推理，因为隐写信息位于权重存储顺序和数值表示中。

### 算法识别与字节序核验

FK、CK 和 Sbox 同时出现时，SM4 的识别已经充分。反编译结果还显示输入按 little-endian `DWORD` 装载，因此轮函数是 SM4，字到字节的装配方向则必须按程序实际行为处理。

解密使用同一轮函数和逆序轮密钥：

```latex
X[i + 4] = X[i] xor T(X[i + 1] xor X[i + 2] xor X[i + 3] xor rk[i])
plaintext = X[35] || X[34] || X[33] || X[32]
```

花括号内部恰好 16 字节，不存在填充或多块链接变量。离线脚本得到明文后，再让原程序输出 `Correct.` 才完成闭环。

## 3.gopherblog

### 总体思路

这题是一条比较标准但很完整的利用链:

1.  搜索接口存在 SQL 注入。
2.  通过 SQL 注入读取 `settings` 表，拿到 `jwt_secret` 。
3.  用 `jwt_secret` 伪造 `role=admin` 的 HS256 JWT。
4.  访问管理员功能 `/admin/newsletter` 。
5.  Newsletter 预览会执行用户可控的 `text/template` 模板。
6.  模板数据中包含 `Mailer` 对象，调用其方法后可以走到命令执行。
7.  利用命令执行读取 `/flag` 。

### 备份加密链的可复核推导

## 6.SecureVault

真实流程是：

1.  用户输入 32 位十六进制字符串
2.  Java 层先做一次置换和异或
3.  变换后的 16 字节结果再传给 `nativeVerify`
4.  native 层校验的是这个“变换后的结果”，不是原始输入

### Java

Java 层主要负责界面和输入，真正的校验逻辑在 JNI 里，也就是 `libnative_crypto.so` 。核心函数是 `Java_com_securevault_locker_NativeBridge_nativeVerify` 。

Java 正向变换为：

## 7.CloudPulse

**前端 (Python/Flask)** 与 **后端 (Go)** 在处理 JSON 键（Key）时的 Unicode 规整化差异

**前端 (Python):** 使用 `lower()` 方法对 JSON 键进行归一化。在 Python 中，字符 `ſ` (LATIN SMALL LETTER LONG S, `\u017f`) 的小写形式仍然是其本身。

**后端 (Go):** Go 语言的 `encoding/json` 包在将 JSON 映射到结构体（Struct）时，会进行大小写折叠（Case-folding）。在 Go 的处理逻辑中， `ſ` 会被视为与 `s` 等价。

#### 第一步：绕过业务逻辑限制

前端代码逻辑

```plain
normalized["ops"] = "httpcheck"  # 强制锁定
normalized["target"] = target
```

构造以下 JSON：

```plain
{
  "ops": "httpcheck",
  "op\u017f": "fetch",
  "target": "..."
}
```

`opſ` 映射到 `Ops` 字段，值变为 `fetch` 。这解锁了危险的后端功能。

#### 第二步：Curl 参数注入

后端在 `fetch` 分支中直接使用了 `strings.Fields(target)` 分割字符串，并将其作为参数传递给 `curl` ：

```plain
targetParts := strings.Fields(target)
cmd := exec.Command("curl", targetParts...)
```

这意味着我们可以通过在 `target` 中加入空格来注入 `curl` 的额外参数。虽然 `-o` 和 `-file://` 被禁用了，但 `-F` **(HTTP 表单上传)** 是可用的。

![](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/08/ea32c6e2276dacf9.png)

### 规整化差异如何影响字段绑定

前端 `lower()` 不会把 `opſ` 变成 `ops` ，Go 结构体匹配却使用 Unicode case-folding，使长 s `ſ` 与 `s` 折叠到同一字段。进入 `fetch` 后， `strings.Fields` 产生独立 argv， `exec.Command("curl", targetParts...)` 使用的是 curl 参数语义而非 shell 元字符；可用的 `-F` 因而成为数据承载点。

## 8.近在咫尺

1.  从 $a = \\lceil\\sqrt{n}\\rceil$ 开始向上遍历。
2.  计算 $a^2 - n$ 是否为一个 **完全平方数**。

### 因数分解方法的适配性

Fermat 分解适用于因子接近的 RSA 模数。令 `n = a² - b²` ，从 `ceil(sqrt(n))` 递增检查 `a² - n` 是否为平方数，命中即可得到 `p = a - b` 、 `q = a + b` 。随后计算 `d = e⁻¹ mod φ(n)` 并做模幂解密；偶数长度十六进制转换可避免前导半字节错位。

def continued_fraction(num: int, den: int) -> list[int]:
    items: list[int] = []
    while den:
        a = num // den
        items.append(a)
        num, den = den, num - a * den
    return items


def convergents(cf: list[int]) -> list[tuple[int, int]]:
    result: list[tuple[int, int]] = []
    n0, d0 = 1, 0
    n1, d1 = cf[0], 1
    result.append((n1, d1))
    for a in cf[1:]:
        n0, n1 = n1, a * n1 + n0
        d0, d1 = d1, a * d1 + d0
        result.append((n1, d1))
    return result


def wiener_attack(modulus: int, exponent: int) -> tuple[int, int, int]:
    cf = continued_fraction(exponent, modulus)
    for k, d in convergents(cf):
        if k == 0:
            continue
        if (exponent * d - 1) % k:
            continue
        phi = (exponent * d - 1) // k
        s = modulus - phi + 1
        disc = s * s - 4 * modulus
        if disc < 0:
            continue
        t = math.isqrt(disc)
        if t * t != disc:
            continue
        p = (s + t) // 2
        q = (s - t) // 2
        if p * q == modulus:
            return d, p, q
    raise ValueError("Wiener attack failed")

    base64_blob = decrypt_type3(frame_174.payload, key.modulus, private_exp).decode()

    print("frame 171 plaintext:")
    print(listing)
    print(" frame 174 base64 prefix:")
    print(base64_blob[:160])

    enc_tar = base64.b64decode(base64_blob)
    enc_tar_path = ROOT / "flag.enc.32.tar"
    enc_tar_path.write_bytes(enc_tar)
    print(f" Wrote {enc_tar_path} ({len(enc_tar)} bytes)")

    passwords = parse_passwords(chain)
    if len(passwords) != 32:
        raise ValueError(f"expected 32 passwords, got {len(passwords)}")

    openssl = find_openssl()
    current = enc_tar_path
    for layer, password in reversed(list(enumerate(passwords, start=1))):
        out_path = ROOT / (f"flag.dec.{layer - 1}.tar" if layer > 1 else "flag.tar")
        cmd = [
            openssl,
            "enc",
            "-d",
            "-aes-256-cbc",
            "-salt",
            "-pbkdf2",
            "-pass",
            f"pass:{password}",
            "-in",
            str(current),
            "-out",
            str(out_path),
        ]
        result = subprocess.run(cmd, capture_output=True, text=True)
        if result.returncode != 0:
            raise RuntimeError(f"openssl failed at layer {layer}: {result.stderr}")
        print(f" Decrypted layer {layer:02d} -> {out_path.name}")
        current = out_path

    extract_dir = ROOT / "flag_tar_extracted"
    extract_dir.mkdir(exist_ok=True)
    with tarfile.open(current, "r") as tar:
        tar.extractall(extract_dir)

    flag_path = extract_dir / "flag.txt"
    flag = flag_path.read_text().strip()
    print(f"flag path: {flag_path}")
    print(f"FLAG: {flag}")


if __name__ == "__main__":
    main()
