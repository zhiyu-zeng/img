> 💡 **AI 总结（key-points）**
>
> 免上传即可在线把 APK 的 dex 反编译成 Java 代码，速度较快，底层使用开源反编译器 garlic。
> 
> - **工具入口：** 在线 APK 解析反编译网站为 ufox.cc/en/tools/apk-decompiler/，宣称不需要把文件上传到服务器。
> - **核心能力：** 支持将 dex 反编译为 Java 代码，处理速度快。
> - **底层反编译器：** 使用开源项目 garlic（github.com/neocanable/garlic）完成 Java 反编译。
> - **评论区反馈：** 有用户询问类似 JADX 的在线网站，指出 decompiler.com 只适合处理小文件；另有用户表示大文件在线处理对服务器压力大，且 JADX 因用 Java 编写较慢。
> - **开发动态：** 有用户（int3bp）在评论区表示正在实现类似 JADX 的在线反编译功能。

支持将dex反编译为java代码 速度快 不需要上传到服务器  
地址: [https://ufox.cc/en/tools/apk-decompiler/](https://ufox.cc/en/tools/apk-decompiler/)  
java反编译器: [https://github.com/neocanable/garlic](https://github.com/neocanable/garlic)
