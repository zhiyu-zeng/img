> 💡 **AI 总结（key-points）**
>
> AI Agent 的安全风险贯穿输入、上下文构建、决策、工具执行到输出全链路，提示词注入之外，敏感信息泄露、工具滥用与越权是主要失陷点。
> 
> - **调用链路即攻击面：** 用户输入/外部内容 → 上下文构建（Prompt、RAG、Memory、Skill）→ 规划决策 → 工具执行 → 结果回传 → 输出，逐环节都可被利用。
> - **Prompt 风险：** 系统提示词泄露本身危害有限，价值在于摸清 Agent 功能与工具编排；间接提示词注入把恶意指令藏在网页、PDF 注释、RAG 数据或 Tool 返回中，绕过用户输入检测；边界混淆则伪造系统消息、角色标记与分隔符，干扰指令来源和优先级判断。
> - **RAG 风险：** 凭据、账号密码误入库且未做识别过滤导致泄露；检索未绑定登录身份、文档切片未继承原权限造成越权；知识库投毒分事实投毒与指令投毒（后者属间接注入）。
> - **Skill 与 MCP Tool 风险：** Skill 可植入恶意指令、携带不可信脚本依赖继承 Agent 权限；自然语言约束非强制控制，可被跳过前置校验。Tool 侧为越权与参数不可信，用户、租户、资源 ID 必须取自服务端登录态或可信上游。
> - **功能安全与实战：** 文件系统隔离不足/任意文件读写、代码执行未隔离（近 RCE）、凭证挂载泄露、网络未限制致 SSRF、数据库越权与 SQL 注入、HTML 生成 XSS。三个案例：xlsx 中埋 XSS payload 配合固定模板生成可分享的存储型 XSS 页面；上传临时 Skill 脚本读取环境变量，API_KEY、SECRET 无脱敏外泄；提示词注入把 `false` 改成 `true` 绕过 Skill 预校验，越权为他人的违规单创建跟进工单。

**chunliunai** *2026年10月11日 10:26*

引言：随着企业 AI Agent 应用不断增多，Agent 开始接入内部数据、业务系统和各类工具，其安全风险也从传统的提示词注入，逐渐延伸至敏感信息泄露、工具滥用、身份冒用与越权访问等问题。本文将结合实际案例，梳理 AI Agent 应用中常见的安全风险面

## Agent应用风险全景

一次Agent的调用链路：用户输入/外部内容 → 上下文构建（Prompt、RAG、Memory、Skill）→ Agent 规划与决策→ Agent 工具执行 → 结果回传/继续决策 → 最终输出

这条链路中的每个环节都可能成为攻击入口，分析Agent风险面也是由这条链路展开，覆盖从输入、决策、执行到输出的每个环节常见风险面介绍

## Prompt安全

## 系统提示词泄露

定义：攻击者通过特殊提示词，诱导模型输出原本隐藏的系统指令

常见方式：直接询问、角色扮演、多轮诱导、编码混淆或利用报错信息提取系统提示词

风险影响：系统提示词本身泄露不能算是比较大的危害，更多的是让攻击者了解Agent的功能、定义、内部编排工具等可能的信息，为后续的提示词注入提供相关信息

## 间接提示词注入

定义：攻击者将恶意指令隐藏在网页、文档、邮件、RAG数据或Tool返回结果中，Agent读取这些内容后将其误认为可信指令

常见方式：在网页隐藏文本、PDF注释、商品描述或知识库文档中植入指令

风险影响：间接提示词注入为攻击者提供了绕过用户输入检测的入口。恶意指令通过文档、网页或工具返回进入上下文后，可能被Agent当作正常指令执行

## 提示词边界混淆

定义：系统提示词和用户输入提示词最终都会进入模型上下文，模型主要依靠角色信息和提示词结构区分两者。当这种边界处理不严时，攻击者可以伪造提示词结构，让模型误判指令来源和优先级

常见方式：在用户输入中伪造系统消息、角色标记、分隔符或结构化标签，利用上下文拼接时缺少转义和隔离，插入看似更高优先级的指令

风险影响：本质上属于提示词注入的一种绕过手法，主要干扰模型对指令来源和优先级的判断，绕过原有提示词限制，实现伪造系统提示词的效果

## RAG安全

很多Agent应用都会配置RAG知识库，用于检索企业内部文档和业务数据，辅助Agent理解问题并完成任务。由于知识库内容会直接进入模型上下文，一旦数据、权限或检索过程存在问题，就可能引发敏感信息泄露、越权检索和知识库投毒等风险

## 敏感信息泄露

定义：知识库本身可能包含业务敏感数据、账户密码、凭证信息，这些内容被检索进入上下文后，可能直接出现在Agent回答中，造成敏感信息泄露

常见原因：开发误将包含数据库账号密码、API Key、用户个人信息或内部敏感数据的文档直接写入知识库，且在文档解析、检索和输出过程中没有进行敏感信息识别与过滤

安全规范：文档入库前应进行数据分类和敏感信息检查，禁止存储账号密码、Token等凭据，检索和输出时再次进行过滤

## 知识库越权检索

定义：多用户Agent应用中，如果RAG检索未校验用户身份和文档归属，可能导致不同用户之间的知识库数据越权访问

常见原因：知识库ID或文档ID可由用户控制，检索时未绑定当前登录身份，或文档切片没有继承原文档权限

安全规范：类似传统的越权漏洞，对RAG检索时绑定当前用户身份，并对知识库、文档及切片进行统一权限校验

## 知识库投毒

定义：攻击者向RAG知识库写入错误内容或恶意指令，影响Agent后续回答和操作

知识投毒：写入虚假、错误或过期信息，影响Agent对事实的判断；可能导致Agent引用错误信息，产生错误回答或业务判断

指令投毒：在知识库内容中植入指令，被召回后劫持Agent任务或工具调用；本身属于间接提示词注入的一种，进一步诱导Agent执行敏感操作

## SKILL安全

Skill通常包含完成特定任务所需的指令、流程和脚本，用于指导Agent进行决策和工具调用。如果Skill本身不可信，其中的风险也会直接影响Agent行为

## SKILL危险指令

定义：本质上是将恶意提示词写入Skill，通过Skill加载进入Agent上下文，诱导Agent执行非预期操作

风险影响：恶意指令可能影响Agent决策，导致读取敏感文件、执行危险命令或向外发送数据等风险

## SKILL脚本和供应链风险

定义：部分Skill会携带脚本、依赖和资源文件，如果来源不可信或依赖被篡改，可能将恶意代码引入Agent运行环境

风险影响：恶意代码可能继承Agent权限，读取本地文件和凭证、执行系统命令，或将敏感数据发送到外部

## 业务流程约束实效

定义：一些业务场景下的Skill会通过自然语言约束Agent完成前置检查、按顺序调用工具或进行用户确认，但这类文本约束并非强制控制，Agent可能跳过或错误执行

风险影响：可能导致Agent绕过业务前置校验，直接执行删除、解绑等敏感操作，或使用错误参数完成业务流程，让未满足业务条件某些资源执行操作

## MCP TOOL安全

通常一个Agent需要完成订单查询、商品管理、退款等具体业务操作，会选择接入各类MCP Tool，由工具调用后端服务并返回执行结果。由于MCP Tool直接接触业务数据和操作，其身份传递、权限校验及参数控制也成为Agent应用的重要风险点

## MCP TOOL越权

定义：可以把用户和Agent看作同一个身份的两个执行点，对业务操作来说，Agent有权调用MCP Tool，不代表当前用户有权访问Tool操作的业务资源。如果Tool未校验当前用户身份、权限和资源归属，就可能产生水平或垂直越权

风险影响：攻击者可能读取或修改其他用户的数据，或通过普通账号调用仅限管理员使用的业务能力

## 调用参数来源不可信

定义：部分Tool参数本应从登录态或前置查询结果中获取，但Agent可能直接使用用户输入或模型生成的值，导致身份、资源ID或业务参数被伪造

风险影响：如果Tool服务端直接信任这些参数，可能造成越权访问、错误业务操作或前置条件绕过

安全规范：用户、租户及权限相关参数应从服务端登录态或可信上游获取，不能直接使用Prompt或模型生成的值；Tool执行前仍需校验资源归属和业务状态

## Agent功能安全

## 文件系统

部分Agent会提供文件系统作为基础能力，使其能够在任务过程中创建、读取和修改文件。该功能主要需要关注文件系统的隔离边界，以及Agent能够操作的文件范围

文件系统隔离

定义：多用户Agent应用中，不同用户的文件系统或工作目录未进行独立隔离

风险影响：导致用户越权读取、修改或删除其他用户Agent工作区中的业务文件、任务产物及记忆文件，造成数据泄露或数据破坏

文件系统内任意文件读写

定义：Agent的文件操作功能未限制可访问路径，用户可以控制Agent读取或修改运行环境中的任意文件

风险影响：可能读取配置文件、密钥、Skill及系统文件，或覆盖、删除Agent运行所需的文件。实际危害取决于Agent文件系统中暴露的数据和权限范围

## 代码执行

部分Agent支持运行代码完成数据处理和自动化任务。该功能主要需要关注执行环境的隔离边界，以及代码能够访问的系统资源

代码执行环境隔离不足

定义：测试Agent代码执行功能时，首先需要确认对应工具是否运行在独立的隔离环境中。如果代码直接在Agent服务所在环境执行，那么该功能本质上就提供了服务端代码执行入口，影响接近RCE

沙箱逃逸

定义：即使代码运行在隔离的沙箱或容器中，也不代表绝对安全。如果沙箱本身存在漏洞或配置问题，攻击者仍可能突破隔离边界，进一步访问宿主机或其他任务环境。成功逃逸后的影响通常接近宿主机RCE；沙箱逃逸涉及容器配置、运行权限和底层漏洞等多个方面，内容较为复杂，本文暂不展开具体介绍

敏感文件与凭证泄露

定义：由于配置不当，数据库密码、API Key、Token等敏感文件或凭证被直接挂载或注入代码执行容器，用户可以通过代码执行功能读取并输出这些信息

风险影响：泄露的凭证可能被用于访问数据库、内部接口或云服务，使攻击范围从代码执行容器进一步扩大到其他业务系统

代码执行环境网络访问未限制

定义：代码执行功能通常可以通过代码或系统命令主动发起网络请求。如果运行环境未限制网络访问范围，攻击者可能借此访问内网服务或云元数据接口，形成SSRF，其危害影响一般就是SSRF能达到的影响

## 数据库查询功能

部分Agent会接入数据库查询能力，用于获取和分析业务数据。该功能主要需要关注数据访问边界和查询过程的安全性

敏感数据越权获取

定义：Agent查询数据库时使用统一的高权限账号，或查询过程没有绑定当前用户的数据权限，导致用户可以获取超出自身权限范围的敏感数据

风险影响：可能造成其他用户、其他租户或内部敏感业务数据被批量查询和泄露

数据的脱敏处理

定义：针对被定义为敏感或高敏的数据字段，数据安全规范通常要求根据数据等级和用户权限进行裁剪或脱敏。Agent查询并输出此类数据时，也应遵循相同要求，避免直接返回明文，若此点没有满足也可以理解为安全风险

参数拼接导致的sql注入

定义：当Agent将用户输入转换为数据库查询参数后，如果工具缺少必要的安全校验，攻击者可能通过Prompt将恶意SQL带入查询，造成SQL注入

风险影响：可能突破原有查询范围，读取未授权数据；如果数据库账号具备写权限，还可能修改或删除数据，甚至可能被进一步利用的空间

## HTML页面生成功能

部分Agent支持根据用户需求生成HTML页面。该功能主要需要关注生成内容和页面渲染过程的安全性。

不安全输出导致XSS

定义：如果Agent支持根据用户需求生成HTML页面，应用直接渲染模型输出且未过滤危险标签和属性，攻击者可能通过Prompt控制页面内容，造成XSS
