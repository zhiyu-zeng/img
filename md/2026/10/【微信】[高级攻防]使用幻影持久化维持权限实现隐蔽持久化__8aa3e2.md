最终，我寻找到了一种极其好用的维持权限方法，该技术由美国幻影安全网络安全公司的总裁 `S1n1st3r` 发现，其核心在于滥用 Windows 的应用重启机制，通过主动劫持关机流程，诱导内核在关机后期自动写入持久化条目，从而规避基于注册表写入监控的检测。因此取名为幻影持久化。

## 二、技术原理

### 1\. Windows 应用重启机制

Windows 提供了一套名为 Application Restart and Recovery 的 API，用于在应用崩溃或系统更新导致重启后自动恢复应用状态。其核心 API 为：

```


1
HRESULT RegisterApplicationRestart(PCWSTR pwzCommandline, DWORD dwFlags);

```

调用此 API 注册后，Windows 会在系统关机/重启时记录该应用的信息，并在下次启动时自动重新启动它。（由系统进程 csrss.exe 在关机流程的最后阶段自动写入注册表）

```


1
HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce\Application Restart #<NUMBER>

```

这意味着操作者进程完全不触碰注册表，从而规避了大多数 EDR 的注册表监控。

### 2\. 关机流程劫持

幻影持久化的精妙之处在于主动劫持关机流程。当系统发起关机时，隐藏窗口会收到 WM_QUERYENDSESSION 消息。操作者在此消息处理中执行以下操作：：

1.  1\. 调用 ShutdownBlockReasonCreate 声明“系统还在关机中”，暂时阻止关机。
    
2.  2\. 调用 AbortSystemShutdown 取消当前关机流程。
    
3.  3\. 启用 SE_SHUTDOWN_NAME 特权。
    
4.  4\. 调用 ExitWindowsEx(EWX_RESTARTAPPS | EWX_FORCE,...) 主动触发带 RESTARTAPPS 标志的重启。
    

## 三. 运行流程

进程启动 调用 RegisterApplicationRestart 注册重启 等待 60 秒以满足系统要求 创建隐藏窗口并进入消息循环 下载并执行远程 Shellcode 系统发起关机 隐藏窗口拦截 WM_QUERYENDSESSION 阻止关机流程 启用 SE_SHUTDOWN_NAME 特权 主动触发带 EWX_RESTARTAPPS 标志的重启 csrss.exe 在关机后期写入 RunOnce 条目 系统重启 explorer.exe 读取 RunOnce 条目 自动启动该应用 重新下载并执行 Shellcode 结束 开始 关机劫持过程 持久化写入过程 重启恢复过程

此方法opsec规避极高，主要体现在：

1.  1\. 持久化由Windows在关机最后阶段写入，不触碰注册表。
    
2.  2\. 关机后期大多数 EDR 监控进程可能已离线，检测概率低。
    
3.  3\. 利用合法系统API。
    
4.  4\. 无需管理员权限
    

微弱缺点：

1.  1\. 强制关机或系统崩溃时持久化无效。
    
2.  2\. 仅适合PC，服务器很少重启，因此效果有限。
