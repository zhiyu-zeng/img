> 💡 **AI 总结（key-points）**
>
> 通过利用 Lua 引擎中变量传输时附带变量名字符串的特性，实现对特定游戏变量的代码注入，成功制作了《王国保卫战》的动态修改器。
> 
> - **核心发现：** 游戏在 Lua 变量传递时，变量值地址的偏移 10 处会存储变量名字符串（如 "player_gold"），可将此字符串用作特征码来区分和筛选变量。
> - **注入点选择：** 在 lua51.dll 的指令 `8B 29 8B 49 04` (mov ebp,[ecx]; mov ecx,[ecx+04]) 处进行 AOB 扫描并 hook，该处 ecx 为变量载体，适合在读写变量前介入。
> - **注入逻辑：** 在注入代码中通过比较 `[eax+10]` 开始的字符串来识别金钱、生命、星星等变量，将对应 ecx 地址保存至预分配的 `man_pointer` 数组，实现跨关卡的动态修改，无需每关手动定位。
> - **脚本实现要素：** 使用 CE 的 `aobscanmodule` 定位注入点，`alloc` 分配代码洞，`label` 定义跳转目标，通过逐字符比较完成字符串匹配，最终通过 `jmp` 返回原流程。

下一步就要开始写注入代码了，这里涉及的就是ce的AOB注入相关的知识点，也就是我们通过aob来搜索我们的注入点，然后在注入点这里的ecx就是运输我们变量的寄存器，我们在注入的代码中实现对于我们特征值（lives，player....）这些的筛选

我的脚本如下

```go
{ Game   : Kingdom Rush.exe
  Version:
  Date   : 2026-07-28
  Author : 93953
  Description : 修改金钱、生命、星
}

[ENABLE]

aobscanmodule(INJECT,lua51.dll,8B 29 8B 49 04 89 2C C2) // should be unique
alloc(newmem,$1000,INJECT)
alloc(man_pointer,24)

registersymbol(INJECT)
registersymbol(man_pointer)

label(original_code)
label(return)
label(restore_reg)
label(check_is_gold)
label(check_is_gold_END)
label(check_is_live)
label(check_is_live_END)
label(check_is_star)
label(check_is_star_END)

newmem:
  pushfd
  push eax
  mov eax,[ecx+08] // 拿到指向字符串结构的指针

// 判断此值的类型是否为金钱(player_gold)
check_is_gold:
  cmp dword ptr [eax+10],'play'
  jne check_is_gold_END
  cmp dword ptr [eax+14],'er_g'
  jne check_is_gold_END
  cmp word ptr [eax+18],'ol'
  jne check_is_gold_END
  cmp byte ptr [eax+1A],'d'
  jne check_is_gold_END
  mov [man_pointer],ecx
check_is_gold_END:

// 判断此值的类型是否为生命(lives)
check_is_live:
  cmp dword ptr [eax+10],'live'
  jne check_is_live_END
  cmp byte ptr [eax+14],'s'
  jne check_is_live_END
  mov [man_pointer+8],ecx
check_is_live_END:

// 判断此值的类型是否为升级用的星(total_stars)
check_is_star:
  cmp dword ptr [eax+10],'tota'
  jne check_is_star_END
  cmp dword ptr [eax+14],'l_st'
  jne check_is_star_END
  cmp word ptr [eax+18],'ar'
  jne check_is_star_END
  cmp byte ptr [eax+1A],'s'
  jne check_is_star_END
  mov [man_pointer+10],ecx
check_is_star_END:

restore_reg:
  pop eax
  popfd
  jmp original_code

original_code:
  mov ebp,[ecx]
  mov ecx,[ecx+04]
  jmp return

INJECT:
  jmp newmem
return:

[DISABLE]
INJECT:
  db 8B 29 8B 49 04

unregistersymbol(man_pointer)
dealloc(man_pointer)
unregistersymbol(INJECT)
dealloc(newmem)
```

注入结束，这下我们就不用每一个关卡都使用手动定位这些金钱血量了

### 学习到的内容

1.  一部分本质就是，在变化中寻找不变，这里的不变是一个我们要找的变量，或者是一段运行过程中的特征代码，然后我们围绕这个“特征值”做文章
2.  **综合思路** ：

1.  就是先寻找到一个变量，然后还原结构体，在相关代码附近发现了其变量名。通过变量名我们就可以对修改的内容进行区分，从而实现修改。
2.  在这个lua引擎的游戏中，对于数值的修改我们发现都经过了一个步骤，就是使用了一个lua的动态链接库中的一段操作，我们讲这段操作码视为特征值，进行代码注入（这里通过AOB相关函数；来实现定位）
