**美创资讯** *2026年11月18日 08:00*

![图片](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/f769fe10a09a203d.gif)

为加速数据安全专业人才的培育，增强企事业单位数据安全治理与防御能力，提升数据安全从业人员的业务能力和管理水平，在中国电子学会、浙江省网安协数据安全治理专委会的支持下，杭州美创科技股份有限公司计划于12月份开展2026年“数据安全咨询（高级）”培训。通过本课程的学习，学员将充分了解数据安全相关法律、法规、标准，掌握评估实践、技术实践和整体建设等，以强化实际工作开展所需的技能。本次培训工作坚持合法合规确保质量。

**培训简介**

**电子信息人才能力提升工程** 是中国电子学会为深入实施人才强国战略，以用人需求为导向面向社会实施的专业技术人才和高技能人才培养项目。 **“数据安全咨询（高级）”** 培训是中国电子学会根据《国家专业技术人才知识更新工程实施方案》和《国家职业教育改革实施方案》，联合大型企业，面向从事信息安全管理、信息安全咨询等相关岗位人才的专业技术培训。培训证书可作为专业技术人员或技能人员考核评价、岗位聘用以及企事业单位相关人员实力的参考依据。

**培训对象**

1、本课程适用全部行业，包括不限于人工智能、数据资产、数据安全、政府、金融、医疗、电力能源、互联网、交通、工业等行业（关基行业应予以重点关注），课程适用岗位不限，欢迎广大有兴趣的人员报名；

2、如从事或准备从事信息安全管理、信息安全咨询、人工智能安全、数据资产管理与运营等相关岗位，应予以重点关注；

3、已完成或正在接受数据安全及相关技术领域专业技术职称评定的初级、中级、高级工程师，以及需要获取继续教育学时（具体以当地主管部门及所在单位认定要求为准）的专业技术人员，均可报名参加。培训学时可按相关规定计入专业技术人员继续教育记录。

4、本课程需具备一定的理解、沟通和逻辑分析能力。

**培训内容**

数据安全咨询（高级）培训内容包括：数据安全基础知识、相关法律、法规、标准知识、数据安全评估实践、数据安全整体建设体系等内容体系；

线上直播形式，共25课时。

|     |     |
| :---: | :--- |
| **主题** | **课程** |
| 一、数据安全基础知识 | （一）数据库基础理论（数据库技术的发展介绍、数据库系统概述、主流关系型数据库介绍）  <br>（二）数据安全基础（数据安全发展概述、数据安全标准、数据安全治理、常见的数据安全技术、数据安全意识、数据安全未来发展） |
| 二、相关法律、法规、标准知识 | （一）国际数据安全合规标准讲解（国际数据安全法律和标准发展、国际数据安全标准详细介绍）  <br>（二）国内数据安全合规标准讲解（国内数据安全标准发展、国内数据安全标准现状、国内数据安全标准详细介绍） |
| 三、数据安全评估实践 | （一）数据安全评估基础理论  <br>（二）数据安全风险评估方法（数据安全风险评估方法、数据安全风险评估流程、数据安全风险分析应用） |
| 四、数据安全技术与实践 | （一）数据安全管理技术应用（数据库防火墙技术应用、数据库审计技术应用、数据库加密技术应用、数据脱敏技术应用、AI 数据安全技术应用）<br><br>（二）数据库安全运维实践（演示环境操作演示） |
| 五、数据安全整体建设体系 | （一）数据安全设计指导理论（数据安全建设指导理论概述、基于风险视角的数据安全设计、由内而外的数据安全分层保护体系）<br><br>（二）数据生命周期安全设计实践（数据采集安全、数据传输安全、数据存储安全、数据处理安全、数据交换安全、数据销毁安全、数据备份管理、数据安全管理） |

注：表格为课程安排计划，具体以实际授课为准。

**考试安排和证书颁发**

集中授课结束后需要参加统一组织的线上考试，学员经培训和考试合格后，由中国电子学会颁发“数据安全咨询（高级）”证书。
