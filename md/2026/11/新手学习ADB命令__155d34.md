## 新手学习ADB命令

根据包名获取APK安装路径

```xml
adb shell pm path <包名>
XML
```

获取手机架构

```
adb shell getprop ro.product.cpu.abi
STYLUS
```

强制安装指定架构的应用

```
adb install --abi armeabi-v7a xxx.apk
adb install --abi x86_64 xxx.apk
STYLUS
```
