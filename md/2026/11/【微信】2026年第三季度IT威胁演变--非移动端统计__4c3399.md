勒索软件

RANSOMWARE

TRENDS季度趋势与要点2.1

威胁行为者遭打击

8 月，Ransom Cartel 勒索软件即服务（RaaS）行动的创建者兼首席管理员被判处 16 年监禁。该罪犯开发了这款勒索木马，被捕时在 RaaS 行动中处于核心位置：负责运营附属成员（affiliate）计划、招募附属成员、向其提供情报与攻击工具、对接初始访问中间商（initial access broker）、与受害者沟通，以及处理赎金支付。

9 月，Ryuk RaaS 团伙的一名成员被判处两年监禁、三年监督释放。2019 至 2020 年间，他与同伙入侵了多家机构的网络，并用 Ryuk 木马加密数据。据公开报道，数百台工作站和服务器被攻陷。检方称，该攻击者从受害者处共收取约 1610 枚比特币（BTC）的赎金。

同样在 9 月，Conti RaaS 团伙的一名成员被判处四年监禁。他被控在 2021 和 2022 年攻击多家企业。除实施攻击外，他还负责开发该团伙的部分恶意软件工具集。

漏洞与攻击

7 月，研究人员发布报告称，Qilin 团伙利用了 Palo Alto Networks 防火墙软件中的 CVE-2026-0257 漏洞。该漏洞允许攻击者绕过身份认证，在无需有效账户的情况下攻陷受害者网络。

CISA（美国网络安全和基础设施安全局）在其「已知被利用漏洞目录」（KEV）中，公布了一批被勒索团伙积极利用的 CVE 漏洞：

-   SonicWall SMA1000 远程访问网关中的 CVE-2026-15409 / CVE-2026-15410。CISA 未指明哪些团伙利用了这些漏洞，但研究人员已将相关活动与 INC Ransom 关联。
    
-   Microsoft SharePoint Server 中的 CVE-2026-45659，可使一个已通过认证的低权限攻击者实现远程代码执行。
    
-   Microsoft Windows 中的 CVE-2025-60710，可使攻击者在本地提升权限。
    
-   VMware vCenter 中的 CVE-2026-59310，可导致未认证的远程代码执行。
    
-   WatchGuard Firebox 中的 CVE-2025-14733，同样可导致未认证的远程代码执行。
    
-   JetBrains TeamCity 中的 CVE-2026-63077，攻击者可通过 agent 轮询协议绕过身份认证，以 TeamCity 服务进程的权限执行操作系统命令。在这一权限层级上执行命令，可能获得对配置、凭据、CI/CD 流水线等资源的访问权限。

macOS 攻击

ATTACKS ON MACOS

HIGHLIGHTS季度要点4.1

第三季度初，Jamf 研究人员发现了一种新的窃密程序 PamStealer。其独特之处在于使用可插拔认证模块（PAM）来校验用户输入的管理员密码。

本季度，Socket 研究人员发现了几起供应链攻击，攻陷了 npm、PyPI 和 Cargo（Rust 包管理器）上的热门软件包。这些包中的恶意载荷在影响其他系统的同时，也针对 macOS。例如 7 月 11 日，一个被感染的 npm 包 jscrambler 被发布，其恶意模块是用 Rust 编写的窃密程序。该窃密程序的目标包括加密钱包、各类服务与浏览器中的机密信息、MCP 服务器配置，以及面向 AI 智能体的 API 密钥。8 月，研究人员检测到针对 Rust crate arrayref、internment 和 append-only-vec 的攻击，其向受害者设备投递了一个 Rust 后门。9 月，MemTensor 的 npm 与 PyPI 包恶意版本被发布，投递了一个 Go 后门，目标是各类服务的机密信息、配置与 API 令牌。

8 月，Jamf 研究人员还报告发现了一个新后门 Overlord。它以伪造的 Zoom 安装程序形式分发，具备相当全面的间谍软件功能——这在 macOS 后门中并不常见：它可以通过麦克风窃听、通过摄像头窥视用户、截取屏幕，并记录键盘输入。

第三季度，我们还发现了 MacSync 加密货币窃密木马与后门的更新版本，其载荷投递方式发生了显著变化。

用户计算机本地感染的统计数据是一项重要指标。这类威胁包括：通过感染文件或可移动介质侵入目标计算机的对象，以及最初以非开放形式进入计算机的对象——后者的典型例子是封装在复杂安装程序中的程序和加密文件。

本节数据基于对以下统计的分析：文件反病毒在硬盘文件被创建或访问时对其进行扫描所产生的统计，以及对可移动存储介质的扫描结果。统计数据来自文件反病毒组件访问时扫描（OAS）与按需扫描（ODS）模块的检测判定，涵盖位于用户计算机或已连接的可移动介质（如闪存盘、相机存储卡、手机、外置硬盘）上的恶意程序检出。

2026 年第三季度，我们的文件反病毒组件记录了 23,733,652 个恶意对象和潜在不受欢迎对象。
