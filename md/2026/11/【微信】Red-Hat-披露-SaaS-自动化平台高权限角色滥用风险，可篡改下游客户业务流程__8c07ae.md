**01**

**Nexcorium 僵尸网络爆发，大量 DVR 监控设备遭劫持组建 DDoS 攻击集群**

奇安信威胁情报披露新型 Mirai 衍生僵尸网络 Nexcorium 攻击活动，该僵尸网络利用 TBK 系列 DVR 设备命令注入漏洞 CVE‑2024‑3721 进行批量入侵，同时搭配硬编码弱口令暴力破解，入侵大量安防视频监控、老旧嵌入式网络设备。恶意样本适配 ARM、MIPS 等多类硬件架构，入侵后配置定时任务实现持久驻留，将沦陷设备纳入 DDoS 攻击集群对外发起大流量洪水攻击。 **大量中小企业安防设备长期不更新固件，直接暴露公网，缺少访问限制**。企业需要梳理安防 IoT 资产清单，升级设备固件版本；禁止监控管理端口直接对公网开放；修改设备默认账号密码；内网部署流量监测，发现异常向外大流量行为及时处置；定期扫描物联网设备漏洞，阻断僵尸网络入侵入口。

**02**

**BPFDoor 新型 Linux 后门泛滥，借助 BPF 绕过防火墙实现隐蔽横向渗透**

安全厂商监测名为 BPFDoor 的新型 Linux 持久化后门攻击活动，该恶意程序依托 Linux 伯克利数据包过滤器 BPF 技术实现流量劫持，能够绕过主机防火墙规则，攻击者可穿透防护建立加密通信通道，在电信、金融、零售行业服务器中被大量发现。 **后门不依赖传统监听端口，常规 netstat 命令无法发现连接痕迹，极大增加运维排查难度。** 攻击者通常通过 Web 漏洞获取初始访问权限，植入 BPFDoor 之后，长期潜伏内网开展凭证窃取与横向移动。运维人员不能只依靠传统命令排查恶意连接，需要监控 BPF 程序加载事件；服务器及时升级内核版本；限制普通用户加载 BPF 模块权限；审计系统加载的内核对象；针对已经受害主机完整重建系统，清除后门，同时排查内网是否存在其他被沦陷主机。

**03**

**Redpanda Connect 未认证远程代码执行漏洞，数据流平台遭批量扫描攻击**

安全研究披露 Redpanda Connect 高危漏洞 CVE‑2026‑123270，产品管理 API 接口默认监听全部网络地址，并且未开启身份认证，未授权远程攻击者发送特制请求即可实现服务器远程代码执行。 **Redpanda Connect 作为开源数据流处理组件，广泛用于日志归集、业务数据流中转，不少企业部署之后直接暴露公网，未修改默认安全配置**。漏洞曝光之后互联网出现大规模扫描探测流量，黑客优先瞄准云上部署实例。很多开发人员关注业务逻辑，忽略中间组件默认关闭认证的安全陷阱。运维应当尽快升级至官方修复版本；临时缓解手段关闭公网访问，绑定本地回环地址；为管理接口增加账号鉴权；资产测绘梳理全网 Redpanda 实例；监控异常 API 调用行为，及时发现漏洞利用行为，防止数据流服务器被攻陷造成业务数据泄露。

**04**

**NVIDIA Linux GPU 驱动高危本地提权，共享 GPU 服务器存在接管风险**

安全研究披露 NVIDIA Linux GPU 驱动存在存续 4 年之久本地提权漏洞，普通低权限本地用户可以利用缺陷提升权限，完全接管共享 GPU 服务器。 **该漏洞影响大量 AI 训练服务器、云 GPU 实例，多用户共享算力场景风险最高，多个普通账号并存时风险被放大。** 很多 AI 研发平台对外向研发人员开放普通 Shell 账号，一旦攻击者拿到普通账号，就可借助该漏洞突破权限隔离，读取模型权重、训练数据集等核心资产。漏洞暂无远程利用方式，但在内网渗透、多租户云环境下威胁突出。运维需要跟进 NVIDIA 官方驱动更新；多用户 GPU 服务器做好账号权限隔离，尽量避免普通用户获得交互 Shell；开启内核审计，监控驱动模块异常调用；定期检查 GPU 服务器登录日志；对 AI 算力资产做好风险评估，降低本地提权漏洞带来数据泄露风险。

**05**

**多 Agent 对话劫持漏洞曝光，Agent 之间通信缺少身份校验引发越权风险**

安全研究团队披露多 AI Agent 协作场景下对话劫持安全缺陷，多个智能体互相调用通信时缺少严格身份与消息校验。 **攻击者伪造 Agent 消息，即可诱导业务智能体越权调用工具、访问内部数据，即便修改用户账号密码，Agent 之间通信令牌依然可以被滥用。** 当下很多企业搭建复杂多 Agent 工作流，依靠 Agent‑to‑Agent 消息传递完成业务，开发人员更多关注单 Agent 提示注入防护，忽略智能体互相通信链路安全。该漏洞不属于传统 CVE 程序漏洞，属于业务逻辑层面安全缺陷。开发团队需要为 Agent 通信增加签名校验机制；对跨 Agent 消息做来源鉴权；设置通信令牌独立生命周期，账号变更同步吊销令牌；审计全部 Agent 之间交互日志；开展 Agent 业务威胁建模，补齐多智能体协作场景安全防护短板。

**06**

**uBlock Origin 广告拦截插件高危漏洞，恶意网站可跨域执行脚本窃取数据**

安全研究员发布预警，知名浏览器广告拦截插件 uBlock Origin 爆出高危漏洞，恶意网页可诱导用户导入恶意过滤规则，实现跨站点脚本执行，访问其他网站页面内用户 Cookie、本地存储等敏感信息。 **漏洞影响多个主流浏览器版本，普通用户浏览恶意网站即可触发风险，不需要额外复杂操作**。该插件全球用户基数庞大，个人、企业办公终端大量安装。目前官方已经发布 1.76.4 修复版本。普通用户尽快升级插件至最新版本，拒绝导入网络来源不明过滤规则；企业终端管理侧统一管控浏览器插件版本，禁止安装非应用商店来源插件；员工安全培训，不要随意导入第三方过滤配置；终端监测浏览器异常跨域脚本执行行为，防范借助浏览器插件开展的数据窃取攻击。

**07**

**Vishing 语音钓鱼攻击大规模爆发，冒充 IT 运维骗取企业 MFA 动态验证码**

Mandiant 披露 ShinyHunters 团伙主导大规模语音钓鱼 vishing 攻击。攻击者冒充企业内部 IT 运维人员致电员工，通过话术诱导受害者提交 SSO 账号密码，同时骗取 MFA 动态验证码，以此绕过二次验证接管企业 SaaS、邮箱、协同办公平台。攻击不依靠软件漏洞，完全依托社会工程学，已经侵入全球数十家政企机构。 **攻击者拿到凭据后会注册陌生设备建立持久访问，窃取业务文档，以此开展数据勒索。** 企业仅开启 MFA 不足以抵御语音钓鱼。企业需要开展针对语音诈骗专项安全培训；部署条件访问策略，对陌生设备登录进行拦截；监控账号异地、异常时段登录行为；建立 IT 身份核验机制，员工接到索要验证码电话可以通过内部渠道核实，降低语音钓鱼造成账号沦陷风险。

**08**

**Interlock 勒索软件利用合法网站投放伪造浏览器更新载荷传播攻击**

安全机构监测 Interlock 新型勒索软件攻击链条，攻击者入侵中小型合法网站，篡改网页代码植入欺骗弹窗，提示用户浏览器版本过低，诱导下载伪造浏览器更新程序。受害者运行程序之后主机植入勒索载荷，对本地与映射网络磁盘文件加密。 **该攻击利用用户日常更新习惯，钓鱼载体托管于可信域名，邮件网关很难直接拦截。受害覆盖教育、零售、制造业。** 攻击者不自建恶意站点，依靠被黑正规网站完成载荷分发，降低被安全厂商标记概率。企业需要提醒员工拒绝网页弹窗内的软件更新，仅从官方渠道升级浏览器；部署终端防护拦截不明可执行文件；Web 服务器做好漏洞防护，防止站点被篡改；监控内网主机批量文件加密行为；定期对网站开展漏洞扫描，避免网站沦为勒索软件传播跳板。

**09**

**Masjesu 僵尸网络瞄准智慧工厂 IoT 设备，出租沦陷设备发起 DDoS 勒索**

Trellix 威胁情报跟踪 Masjesu 僵尸网络，该恶意家族专门针对智慧工厂 IIoT 设备，入侵工业传感器、仓储机器人、厂区监控设备，把沦陷设备组建为 DDoS 攻击网络。攻击者在 Telegram 渠道对外出售攻击能力，向工厂企业发送勒索威胁，如果不支付赎金，就直接对企业自身业务 IP 发起大流量 DDoS，造成生产线业务中断。 **该恶意软件适配 ARM、MIPS、AMD64 多种硬件架构，擅长在嵌入式设备中长期潜伏。很多工厂工业物联网设备缺少安全运维，固件长期不更新，直接接入企业办公网络**。制造企业需要隔离工业物联网网络与办公网络；修改设备默认口令；定期巡检 IoT 设备运行日志；部署流量异常监测；建立 DDoS 应急处置预案，防范僵尸网络带来业务中断风险。

**10**

**Red Hat 披露 SaaS 自动化平台高权限角色滥用风险，可篡改下游客户业务流程**

安全研究人员发现主流 SaaS 自动化工作流平台存在权限配置缺陷。攻击者利用平台过度授权 IAM 角色，配合自动化密钥扫描脚本，冒充非人类服务账号，读取甚至修改下游客户工作流配置，窃取平台存储 API 密钥与业务凭据。该风险不是程序 CVE 漏洞，属于云多租户环境下配置错误引发供应链风险，一旦平台被攻陷，风险会传导给全部接入该服务的企业客户。 **很多企业开通 SaaS 自动化服务之后，默认接受平台授权，后期不再复核权限范围。** 企业应当定期审计 SaaS 平台分配的角色权限，落实最小权限原则；轮换平台存储密钥凭据；监控服务账号异常访问行为；对第三方自动化平台做定期安全评估，及时回收闲置授权，规避因 SaaS 配置失误带来的数据泄露隐患。
