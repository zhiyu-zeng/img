伴随台海局势变化，台军部队面临作战场景多元化与快速机动作战需求。为有效保障信息作业及通讯畅通，运用无人机结合中继通讯技术，能够迅速完成部署接替，显著提升部队作战效能。

本研究全面收集并分析了无人机相关的通讯技术，将其通讯架构归纳为“单一中继”、“多用户中继”、“多跃中继”及“网状网络中继”等四类。这些架构能够在战场环境中快速构建临时通讯网络，突破地面固定平台的地形限制及传输距离问题，并实现即时接替与支援。

通过探讨各国无人机中继通讯实例与面临的威胁限制，并结合台军机动部队现行通讯中继手段的分析比较，提出了后续精进策略与建议。期盼通过导入相关技术，强化通讯电磁部队在复杂环境下的指挥控制生存性与机动作战优势。

一、前言

随着现代化战场形态朝向数字化与网络化快速演进，通讯链路的稳定性已成为部队遂行分散式作战与快速反应的关键。在复杂的地缘环境与电磁干扰下，无人机凭借其高度机动性与部署弹性，成为延伸通讯距离、克服地形遮蔽不可或缺的通讯手段。本研究的核心架构聚焦于“单一无人机中继网络”、“多用户无人机中继网络”、“多跃无人机中继网络”及“无人机网状网络中继架构”等运用。

考量未来作战环境多变，单点中继已难以满足大范围机动部队的协同需求，本文旨在探讨其在复杂作战环境下如何运用单一及多用户无人机网络与多节点跳接等技术达成通讯中继任务需求，并结合现况运用分析，具体说明各类架构在支援部队作战实际效能发挥与战术限制，以期为未来指管体系提供具实务价值的参考依据。

二、无人机中继架构与通讯技术应用探讨

单一无人机执行中继任务具有信号来源端与接收端，在两端距离过远或存在城市、高地等通讯障碍时，可运用无人机作为中继节点进行信号传递。可通过放大转发或解码转发中继模式，对所传送信号进行优化。多用户无人机中继网络运用单一无人机，对位于地面的多个用户进行信息传输，此架构需要专门设计和优化多重存取协议，使无人机能有效服务地面用户。

多跃无人机中继网络运用多个无人机作为中继节点，协助远距离或复杂环境下的通讯传输，通过寻找合适的无人机中继数量与间距，避免相互干扰。无人机中继网状网络架构则针对大型场景，形成多层中继平面，支持多对多点通讯。 在通讯中继运用上，无人机凭借低成本与高机动性优势，能低速滞空、相对隐匿且不易遭敌锁定，成为战场通讯韧性与备份的关键选项。

例如，在灾害防救领域，无人机能搭载Wi-Fi或4G/LTE微型基站，迅速在孤岛或受灾区域架设临时通讯网络。法国、西班牙等国均有运用系留无人机执行军事或城市通讯中继的实例；中国解放军某通讯团也曾于高原环境成功测试平原型无人机中继平台，突破装备极限；台湾地区相关企业亦发展出具备群飞通讯中继站功能的无人机，配合卫星设备迅速恢复灾区通讯。

三、无人机中继通讯威胁限制及未来发展

无人机中继通讯运作依赖“无人机间骨干与控制网络”及“对地任务中继网络”。在威胁方面，定位系统易受干扰，攻击者可发送同频或大功率伪造GPS信号实施欺骗攻击；网络通讯安全方面，易遭大功率信号干扰导致通讯中断，或遭敌实施恶意中间人攻击截获数据，甚至夺取无人机控制权。

在运用限制上，商用无人机频段受国际电联限制，军事运用则需足够带宽以满足传输距离及高解析度影像需求，频段挤压会影响“展频”与“跳频”抗干扰能力；此外，无人机作为通讯平台还受到载荷、电源功率、散热以及极端天气（强风、降雨、低温等）的显著制约。

未来发展方面，需与有人系统高效协同，发展防止被黑客侵入的飞控系统；在抗干扰技术上，通过空间过滤及自适应波束成形技术降低辐射干扰，导入跳频展频、直接序列展频与跳时展频等技术，并结合多元化卫星导航系统强化定位能力。通讯安全上，应建立高效安全验证机制，引入量子加密技术、多重身份验证及零信任架构。天线技术则朝智能化与自主化发展，通过全球卫星导航系统与视觉感知数据，自动调整天线指向，提升追踪精度与通讯链路稳定性。

表1：抗干扰技术说明

|     |     |     |
| --- | --- | --- |
| **技术** | **说明** | **抗干扰特点** |
| **跳频展频 (Frequency-Hopping Spread Spectrum，FHSS)** | 传输时将载波频率依伪随机序列快速在多个子频道中跳频。 | 因为频率不固定，窄频干扰在一个频率上只能干扰短暂时间；跳频使攻击者难以锁定频率。 |
| **直接序列展频 (Direct-Sequence Spread Spectrum，DSSS)** | 将讯号以伪随机码展频，使讯号带宽远大于原始讯号，接收端以相同码进行解展频。 | 展频后讯号被「藏」于较宽频带内，干扰者须产生大功率覆盖整个频宽；在解展频阶段可降低干扰影响。 |
| **分码多工存取 (Code-Division Multiple Access，CDMA)** | 各使用者共用同一频道／频宽，但每个使用者被指派不同的码；资料与码相乘后传送，接收端用相同码解码。 | 利用不同码即使有其他用户或攻击者干扰，合法码序列可使接收端分离出目标讯号；扩频特性也具抗干扰效果。 |
| **分时多工存取 (Time-Division Multiple Access，TDMA)** | 频道按时间分时切割给不同使用者，在不同时间时槽传送资料。 | 在干扰管理方面，透过时间同步分配与时段切割，可降低因同步错误或撞频造成的干扰；亦可搭配跳频或码改变以增强抗干扰。 |
| **跳时展频 (Time-Hopping Spread Spectrum，THSS)** | 将传输时间划分为连续的讯框，每个讯框再细分为多个微小的时槽，发送端依据伪随机码，在每个讯框中选定一个特定的时槽发送脉冲讯号。 | 由于脉冲发送的具体位置在讯框内是随机跳变的，攻击者难以预测发送时间（具备低截获机率 LPI）；若要干扰，必须在整个讯框的所有时段持续发射大功率杂讯，极大消耗干扰者能量。 |

四、资通电军机动部队精进策略刍议

台军机动部队现行配备包括维星车、微波车及携行式微波系统。维星车属“静中通”构型，能在地面骨干受损时通过卫星链路达成跨作战区情报共享，但缺乏行进间通讯能力，且定点发射高功率信号易遭敌锁定摧毁。

高容量微波车能提供高带宽传输，担任骨干接替与雷达情报回传，但受限“点对点视距无遮挡”物理特性，极易在山隘或城镇产生通讯死角，开设耗时且面临反辐射攻击威胁。携行式微波系统虽可由人力搬运至制高点，但天线桅杆等组件笨重，架设耗时，极易因强风发生微小位移导致信号衰减，无法适应快速多变的作战节奏。

针对现行限制，精进策略建议在山隘通讯延伸中运用单一无人机中继，升空越过山脊线形成“倒V字型”通讯路径，借由低功率定向天线降低遭敌侦测风险；在滨海滩岸或纵深防御中采用多用户无人机中继，作为空中基站自动分配带宽，克服地形遮蔽并满足广域指挥需求；在深入山脉或敌后城镇的远距任务中，采用多跃无人机中继，使多架无人机自动排列成链状，通过跳跃式传输突破单一平台视距限制。去中心化的多跃网络具备极高战术韧性，即便部分节点遭毁，系统也能自动路由重组，确保整体网络不致瘫痪，有效应对现代消耗战。

五、结论

针对台军机动部队在现代化多领域作战环境下，导入无人机中继通讯架构的可行性与战术价值进行了全方位的探讨。经由文献回顾、技术架构分析及案例对照，本文指出将通讯节点由传统的平面部署提升至立体空间，不仅是突破台湾地区复杂地形限制条件的方法，更是建构高韧性战场指挥链路的关键手段。

现役的维星车面临带宽资源有限及反卫星武器威胁，而微波车与携行式微波系统受限于无线电波直线传播的物理特性，在陡峭山隘与城镇建筑中极易因视距遮蔽导致通讯中断，存在显著的“通讯静默区”。导入无人机中继技术，并非完全取代现有的卫星与地面微波系统，而是建立一套“多层次、立体化、高韧性”的备用架构。通讯是指挥的灵魂，韧性是存活的关键。
