**马哥网络安全** *2026年11月10日 17:00*

很多人觉得打点就是要搞到一个 0day 或者 RCE 才有面子。但实战中拿分最多的，永远是 **弱口令** 和 **未授权访问**。

**本质原因**：企业的安全建设不可能面面俱到。他们可能把核心业务系统守得滴水不漏，但边缘系统、测试环境、docker 容器根本没人管。而你作为攻击队，需要的不是最强的漏洞，而是防守方最薄弱的环节。

自动化扫描在这个阶段的价值不可替代。你手动测一个点的时间，自动化指纹识+精准0day利用已经干内网了

### 案例一

### 信息泄露 + 弱口令打穿

##### 三要素信息泄露

通过 Fuzz 发现该网站存在路径遍历，直接泄露 1000+ 条敏感信息：

![图片](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/334dd006ef66c801.png)

```
https://[域名]/yongli-1/20241126/[文件ID].jpg
```

**这类信息泄露的威力**：姓名、身份证、手机号可以直接用于社工、密码重置、钓鱼攻击。而且你不需要任何漏洞，只需要扫目录发现未做权限控制的静态文件。

### 案例二

### Geoserver RCE → Nacos → SSH

##### Geoserver RCE

```
https://[域名]:8055/geoserver/wfs
```

Geoserver WFS 接口存在未授权 RCE 漏洞，直接打入内存马：

```
加密器: JAVA_AES_BASE64
密码: des
密钥: des
请求路径: /*
请求头: User-Agent: Ehkxujyeb
脚本类型: JSP
```

![图片](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/792e28454394d875.png)

##### Suo5稳定隧道

```bash
./suo5 -d --ua 'password' -t http://
./suo5 -d -l 0.0.0.0:7788 --auth test:test123 --ua 'password' -t http://xxx
```

##### Nacos弱口令 → SSH

```
http://[内网IP]:8848/nacos/
修改用户密码：nacos/nacoshvv@123

[+] SSH [内网IP]:22:admin password
```

![图片](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/a59f7f5254227376.png)

**一条链**：Geoserver RCE → Nacos 配置泄露 → SSH 内网主机。

### 自动化打点的正确姿势

##### 指纹识别先行

Finger 或 Ehole 扫资产，识别框架和中间件版本

##### Nuclei/Xray批量

全端口 URL 送进 Nuclei，常用POC自动跑；Xray被动加Rad爬虫深度检测

##### 弱口令专项

-   Nacos: admin/admin, nacos/nacos
    
-   SSH: root/123456, root/root
    
-   MySQL: root/root, root/123456
    
-   Redis: 未授权, 123456, 111111
    
-   XXL-JOB: admin/123456
    
-   华为防火墙: admin/Admin@123
    

##### MS17-010专项

只要内网有 Win Server 2008/R2，必扫永恒之蓝，中奖率超过30%

##### 敏感信息专项

-   路径遍历：/backup/ /upload/ /assets/
    
-   ES未授权：:9200/\_cat
    
-   目录浏览：/files/ /download/
    
-   源码泄露：.git/.env/ WEB-INF/
    

### 总结

**你不需要漏洞多高端，你需要覆盖面够广。**

JeecgBoot 模板注入再香，也不是每个目标都有。但弱口令、未授权、永恒之蓝这三个东西， **每个目标都有**。关键区别在于你是否扫到了那个端口，是否试了那组密码。

自动化扫描加弱口令字典加指纹识别，这三件套配齐，不出成果的概率几乎为零。 **人和机器的配合，才是打点的最高境界！**
