护网复盘：九成失分源于你台账外的影子资产——你不知道的，红队全知道。

资产台账影子资产护网备战

● **一句话精华**  
台账不是架构部的表，是安全的一道命门——你不知道的资产，红队全知道。

护网复盘里有个数据反复看到：好多家单位失分，九成以上栽在“影子资产”上。

你台账里没有的 IP、废掉的子域名、早忘了的测试系统、传错到 GitHub 的密钥——这些恰恰是对方进门的台阶。

这篇文章不跟你讲“资产台账怎么填漂亮”，就说：怎么用一张表，把护网最怕的影子资产管住。

## 00台账不是“系统名单”，是四个问题的答案

很多单位不是没表，是表里只有“我们有哪些系统”这一栏，剩下全是空的。等红队进来了，才慌着问“这玩意儿谁家的”。

|     |     |     |
| --- | --- | --- |
| 要回答的问题 | 对应字段组 | 答不上来会怎样 |
| 我们到底有什么？ | 身份组 | 家底说不清，护网靠猜 |
| 出了事找谁？ | 责任组 | 最贵的成本不是修，是找人 |
| 它暴露在哪、连着谁？ | 技术组 | 一个系统停，连带崩三个 |
| 哪些该收、哪些该退？ | 价值组 | 重复建设和失控暴露年年在花钱 |

业内做资产清单通用的十几个字段（责任人、互联网暴露面、软件版本、处理的数据、认证方式、依赖、供应商、关键等级、最后核查时间），本质就是这四组的展开。

## 01一张表，只记 12 个字段

分四组，每组三个，谁都填得出来。别一上来设计五十列，那是台账死得最快的方式。

**① 身份组**：系统编号（唯一 ID，一切关联的锚）、系统名称（写人话全称，别只写内部缩写）、业务域（归哪条业务线）。

**② 责任组**：业务负责人（提需求、认效果）、技术负责人（能拍板、能签字）、运维厂商（合同乙方，出事第一联系人）。我见过出事时最贵的成本不是修系统，是满世界找人——这一组就是为这个填的。

**③ 技术组**：部署形态（云上 / 本地 / 混合）、技术栈（数据库 + 中间件，判断技术债）、上下游依赖（跟谁说话、谁依赖它，停机评估和攻击路径全靠这栏）。这组的“互联网暴露面”一栏，护网前必须单独标红：哪些公网可达、要不要认证、有没有暴露管理口。

**④ 价值组**：系统分级（A 命脉 / B 重要 / C 一般）、年运维费用、合同到期日。

再加一个颜色：每行涂红黄绿。绿是有人有钱有合同跑得稳；黄是能用但别扭（版本旧、没人熟、快到期）；红是没人认领、合同将到期、公网裸奔、出过事故。一句实话——红色那几行，就是护网前第一件要办的事。

## 02五步把台账建起来，两周出第一版

**1\. 定口径**：先说清什么算“一个系统”。建议口径——有独立部署、有独立负责人、有独立预算或合同，三条占两条就算一个。口径不定，后面必然扯皮。

**2\. 找全（打底 + 攻击者视角）**：别只信各部门上报。从四个来源交叉对账——合同与采购清单、域名与 IP 清单、监控告警清单、财务付款台账——经验值比“拍脑袋上报”多出 20%–30% 的幽灵系统。再用 FOFA、ZoomEye 从外网反查公网资产，跟内部台账一比对，没登记的影子资产立马现形。

**3\. 填表**：先只填 6 个必填——编号、名称、业务域、分级、技术负责人、运维厂商。其余 6 个，用起来自然有人补。

**4\. 认领**：每个系统必须有人签字。这一步最得罪人，也最关键——“待认领”三个字本身就是一张风险清单。

**5\. 定更新**：季度全量复核 + 变更即时触发。新系统上线、下线、负责人变更、合同续签，四个动作必须同步改台账。把“台账已更新”写进上线验收项，否则半年必烂。

## 03红黄绿分级，护网怎么用

去年护网前，我帮一个客户做资产摸底。他们 CMDB 登记了 120 个系统，我拿 FOFA、ZoomEye 从攻击者视角反查公网资产，一比对——多出来快 40 个没人认领的 IP 和废弃子域，还有人在 GitHub 上传了带内网密码的配置文件。护网真打起来，红队就是从这些“台账外资产”进的门。

所以红黄绿不是装饰： **🟢 正常资产** 常态化监控； **🟡 待核实的** 先更新台账核验； **🔴 无认领、公网裸奔、密钥泄露的**，护网前一律先收敛——下线废弃环境、公网高危端口（3389、22、445、6379、27017 这类）收进堡垒机、泄露密钥立即轮换。据公开护网复盘资料，企业外网暴露资产普遍比内部台账多 30%–50%，这部分就是失分重灾区。

● **老宋说**

这不是一张管理表，是安全防线最底层的一块砖。资产不清，后面所有检测、防护、溯源都是建立在流沙上——你连有什么都不知道，谈什么守住。

现在很多单位把资产梳理当成“迎检作业”，检查前突击填、检查完锁抽屉。可攻击者不按你的检查周期来，AI 自动化侦察 7×24 小时扫你的暴露面，台账一过期，缺口就露出来。

你现在能做的第一件事很简单：先把“待认领”那几行清零，再把公网裸奔的系统收进零信任或堡垒机。这两件事做了，护网你就少踩一大半坑。
