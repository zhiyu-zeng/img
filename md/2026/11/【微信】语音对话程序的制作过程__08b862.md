目前大家应用多的语言对话程序有早期的小爱同学、天猫精灵到现在的豆包。包括衍生品豆包输入法、千问输入法。

这里面涉及到两块知识点，一个是语音转文字（输入法用的比较多），一个是文字转语音。

硅基流动上正好有用于实验的语音 API，可以用这些 API 构建一个语音对话程序 Demo 。

![图片](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/9caad72bc47a3e3a.png)

语音模型一般只有 0.5B 大小，和对话模型动辄671B无法比。构建一个语音对话程序需要三个模型，除了两个语音模型，还要有一个对话模型。

以硅基流动的 API 为例，将模型以及 API key 准备好，其中语音模型的 API url 格式为：

```bash
https://api.siliconflow.cn/v1/audio/speech
```

模型用的下面几个：

```javascript
文字转语音：FunAudioLLM/CosyVoice2-0.5B
语音转文字：FunAudioLLM/SenseVoiceSmall
对话模型：deepseek-ai/DeepSeek-V4.1-Flash
```

语音 API 请求的 demo:

```swift
curl --request POST \
  --url https://api.siliconflow.cn/v1/audio/speech \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "fnlp/MOSS-TTSD-v0.5",
    "input": "你站在桥上看风景，看风景的人在楼上看你。明月装饰了你的窗子，你装饰了别人的梦",
    "voice": "fnlp/MOSS-TTSD-v0.5:alex",
    "response_format": "mp3"
  }' --output output.mp3
```
