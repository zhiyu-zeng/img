一、数据安全融合的六大技术体系与思想来源

1\. 传统信息安全体系：CIA安全属性思想

这是数据安全最基础的理论来源。传统信息安全主要围绕信息资产的三个基本安全属性展开：

·保密性（Confidentiality）：防止信息被未授权获取。

·完整性（Integrity）：防止信息被未授权篡改、破坏。

·可用性（Availability）：确保信息及相关服务能够正常使用。

这三个属性构成了传统信息安全理论的经典框架。数据安全继承了这一思想，但保护对象从传统的信息系统、信息资源进一步明确到数据本身。

|     |     |
| --- | --- |
| 传统信息安全思想 | 数据安全中的体现 |
| 保密性 | 数据访问控制、加密、脱敏、防泄漏 |
| 完整性 | 数据校验、防篡改、数据备份与恢复 |
| 可用性 | 数据容灾、备份、恢复、持续服务保障 |

数据安全继承了传统信息安全的基本保护属性，但将其保护对象进一步延伸至数据及其处理活动。

2\. 网络安全与信息系统安全体系：纵深防御思想

网络数据并不是孤立存在的，依赖计算、存储、网络和应用环境。因此，传统网络安全和信息系统安全的技术体系自然成为数据安全的重要基础。

主要包括：

·网络安全架构与纵深防御

·网络安全等级保护

·身份鉴别与访问控制

·边界防护与区域隔离

·主机、操作系统和数据库安全

·安全审计与日志管理

·入侵检测与安全监测

·漏洞管理与安全运维

这里特别值得关注《数据安全法》第二十七条：利用互联网等信息网络开展数据处理活动，应当在网络安全等级保护制度的基础上履行数据安全保护义务。

这不是简单地要求数据安全重复建设一套网络安全系统，而是明确了网络安全等级保护作为数据安全基础保障的制度关系。

数据安全吸收了网络安全的基础设施保护、纵深防御和安全运营思想，但保护重点进一步从系统环境延伸到数据本身。

3\. 数据库安全与数据安全工程体系：以数据为中心的保护思想

在数据安全法出台之前，数据库安全、数据存储安全、数据访问控制、数据备份恢复等技术已经发展多年。

传统数据库安全主要解决：

·数据库身份认证

·数据库权限管理

·数据访问控制

·数据库审计

·数据加密

·数据脱敏

·数据备份与恢复

·数据库漏洞及配置安全

而随着大数据平台、数据仓库、数据湖、分布式存储和数据中台的发展，数据安全保护逐渐不再局限于数据库本身，而是扩展到多源数据、异构存储、数据交换和数据流通。由此形成了一个重要转变，从保护数据库及其运行环境，转向保护数据资源及其处理过程。

这里的核心思想是以数据为中心（Data-Centric Security），而不是仅仅以网络边界、服务器或应用系统为中心。这也解释了为什么今天的数据安全需要但不能仅靠防火墙、入侵检测、主机防护和数据库审计来完成。

4\. 分类分级保护体系：基于重要程度实施差异化保护的思想

这是数据安全非常重要的制度和方法论来源。过去的信息安全保护，已经存在根据系统重要程度、信息敏感程度和安全影响实施差异化保护的思想。

例如：

·信息系统安全等级保护

·涉密信息系统分级保护

·信息分类与敏感性管理

·基于安全等级的访问控制

《数据安全法》第二十一条进一步明确建立数据分类分级保护制度。其判断依据不是单纯的数据敏感程度，而是数据在经济社会发展中的重要程度，以及数据遭到篡改、破坏、泄露、非法获取或者非法利用后可能造成的危害程度。

由此形成：

·一般数据的基础保护

·重要数据的重点保护

·国家核心数据的更加严格保护

体现了一个重要的安全思想是安全保护资源应当与保护对象的重要程度和可能造成的危害相匹配。与传统网络安全等级保护有相通之处，但不能把数据分类分级直接等同于信息系统定级。两者保护对象、评价维度和实施方法均有区别。

5\. 数据全生命周期管理体系：过程控制与持续保护思想

传统信息安全往往以信息系统为保护对象，关注系统建设、运行和维护过程中的安全要求。而数据安全进一步突出数据处理活动本身，涵盖数据全生存周期的安全。

《数据安全法》第三条将数据处理明确为：

·收集

·存储

·使用

·加工

·传输

·提供

·公开

第二十七条又明确要求建立健全全流程数据安全管理制度。

实际上现代数据安全吸收了两个重要思想：

第一，生命周期管理思想。

不再把数据安全理解为某一个存储环节或传输环节的安全，而是关注数据从产生、流转、使用到退出的整个过程。

第二，过程控制思想。

安全不能只通过结果检查来判断，而应当在每个处理环节建立相应的控制要求、操作规则和技术措施。

例如，数据从内部数据库向外部合作方提供时，不仅要考虑传输加密，还要考虑提供的必要性、数据范围、接收方管理、授权关系及后续使用约束。从传统信息系统安全建设思想，进一步发展为面向数据处理活动的全过程保护思想。

6\. 国家安全与战略资源保护体系：数据安全的国家安全观

这一点是《数据安全法》最具中国特色、也是与传统信息安全技术体系区别非常明显的部分。过去的信息安全更多从信息资产、信息系统及组织自身利益出发。但《数据安全法》第一条明确提出维护国家主权、安全和发展利益，第四条明确要求坚持总体国家安全观。

这使数据安全不再只是一个技术问题，也不只是一个企业内部管理问题。而是还融合了：

·国家安全观

·重要战略资源保护思想

·国家数据安全战略

·数据主权与安全利益

·数据安全审查

·数据出口管制

·数据跨境流动安全管理

尤其是第二十一条的国家核心数据保护、第二十四条的数据安全审查、第二十五条的数据出口管制，都体现出数据安全与国家安全治理体系之间的紧密联系。将数据从一般的信息资源提升为关系国家安全、经济发展和社会公共利益的重要战略资源。

二、一个贯穿体系的重要思想：安全与发展的平衡

这个思想不应简单列为一项技术体系，是《数据安全法》非常重要的立法理念。传统信息安全建设容易形成一种倾向，通过限制访问、隔离网络、禁止流动等方式实现安全。但是，数据具有资源属性和价值属性。如果数据只能保护而不能合法利用，数据安全建设就可能失去实际意义。习近平总书记强调坚持统筹发展和安全，为我们筑牢国家网络安全屏障提供了指引，

《数据安全法》第七条、第十三条明确提出保障数据依法有序自由流动，以及以数据开发利用和产业发展促进数据安全，以数据安全保障数据开发利用和产业发展。

这实际上融合了：

·信息资源开发利用思想

·大数据技术与产业发展思想

·数据资源价值化思想

·安全与发展协同治理思想

因此，数据安全不是单纯追求数据不泄露、不被篡改、不被破坏，而是要确保数据处于有效保护和合法利用的状态。这是《数据安全法》第三条对数据安全所作定义中非常值得重视的内容。

四、综述

《数据安全法》并不是凭空创造了一套全新的安全技术体系，而是将过去分散在信息安全、网络安全、数据库安全、信息分级保护、数据治理以及国家安全等领域的技术能力和治理思想，以数据为核心重新组织起来，并通过法律制度予以系统化。

这种变化至少有三个层次：

1.保护对象发生变化：从信息系统、网络设施和信息资产，进一步转向数据本身。

2.保护范围发生变化：从系统运行环境安全，进一步扩展到数据处理全过程。

3.保护目标发生变化：从传统的信息安全属性保障，进一步发展到数据有效保护与合法利用、国家安全与经济社会发展相协调。

《数据安全法》所描绘的数据安全是传统信息安全理论、网络安全技术体系、数据安全工程、分类分级保护思想和国家安全治理理念在数据这一核心对象上的融合与发展。
