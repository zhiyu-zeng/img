## Immobilizer ECDSA

> 核心思路：40 条 secp256k1 ECDSA 签名的 nonce 最高 8 位恒为 0，构成隐藏数问题（HNP），用 LLL 格规约恢复私钥 `d` ，再以 `SHA256(d)` 作为密钥流异或解密 `sealed` 得到 flag。

## 1\. 题目说明

题目只给出一个 `data.json` ，内容为汽车防盗器（immobilizer）的签名记录：

已知条件与约束：

-   曲线为 secp256k1：，素域 ，基点 `G` 的阶为 `n` （256 位素数）。
    
-   40 条签名的消息格式完全固定，只有计数器不同： `immobilizer|vin=LDC613P23A0000001|ctr=i` ， `i = 0..39` 。
    
-   40 个 `r` 两两不同，所以不存在 nonce 直接复用。
    
-   `sealed` 为 27 字节的十六进制串，没有说明加密方式。
    

目标：恢复签名私钥，解开 `sealed` 。

## 2\. 解题思路

```
40 条签名、r 互不相同，但共用一个私钥
  → 每条签名都把 nonce k_i 写成私钥 d 的线性函数：k_i = A_i + B_i·d (mod n)
  → 猜测 nonce 生成存在偏置（高位为 0），即 k_i 远小于 n
  → 构成 HNP，用格 + LLL 找出短向量 (k_1, ..., k_N)，同时得到 d
  → 用 d·G == Q 校验私钥
  → 用 d 派生密钥流解密 sealed
```

## 3\. 解题过程

### 3.1 把每条签名改写成关于私钥的线性方程

**关键观察：** 签名量很大（40 条），又全部出自同一私钥，消息几乎相同。没有重复 `r` ，只能从 nonce 的统计结构入手。

**原理与操作：** ECDSA 签名满足（在 中）：

```
s_i = k_i^{-1} · (z_i + r_i · d)   (mod n)
```

移项得：

```
k_i = s_i^{-1}·z_i + s_i^{-1}·r_i · d = A_i + B_i·d   (mod n)
A_i = z_i · s_i^{-1} mod n,   B_i = r_i · s_i^{-1} mod n
```

其中 `z_i` 为消息摘要。题目没有说明哈希算法，这里取 ECDSA/secp256k1 最常用的 SHA-256： `z_i = int.from_bytes(SHA256(msg_i), "big")` 。（这一选择属于假设，最终靠 `d·G == Q` 来确认。）

**本步结果：** 得到 40 个关于未知数 `d` 的线性同余式， `A_i` 、 `B_i` 均可从公开数据算出。若 `k_i` 是 `[1, n)` 上的均匀随机数，这些方程不泄露任何信息；只要 `k_i` 有界，就能转化为格问题。

### 3.2 建立 HNP 格并估计所需签名数

**关键观察：** 嵌入式 nonce 生成器经常把较短的随机数当作 256 位标量使用，导致高位恒为 0。假设 ，其中 。

**原理与操作：** 存在整数 使 。构造如下格（为保持整数，整体乘以 `n` ），行向量：

```
row_i   (0 ≤ i < N) : (0, …, n·n (第 i 列), …, 0,   0,   0  )
row_N               : (B_1·n, …, B_N·n,            K,   0  )
row_{N+1}           : (A_1·n, …, A_N·n,            0,   K·n)
```

## 2\. 解题思路

1.  观察参数结构（ `q = 7681` 、 `n = 32` 、 `m = 64` 、矩阵 `A` 和向量 `b` ），判定其为标准 LWE 样本集 `b ≡ A * s + e (mod q)` 。
    
2.  由于秘密维度 `n = 32` 很小且模数 `q = 7681` 较大，构造 `m + n + 1 = 97` 维的 Kannan 嵌入格基，将求解小误差 `e` 与小秘密 `s` 的问题转化为格上的最短向量问题（SVP）。
    
3.  对 97 维格基运行 LLL 约减，直接从约减基首行提取出二元秘密向量 `s ∈ {0, 1}^32` 和三元误差向量 `e ∈ {-1, 0, 1}^64` ，并代回原方程校验全部 64 个样本同余关系成立。
    
4.  将 32 维向量 `s` 按单字节序列 `bytes(s)` 计算 `SHA-256` 摘要，取前 28 字节与 `masked_update` 逐字节异或，解出明文 Flag。
    

## 3\. 解题过程

### 3.1 识别 LWE 样本参数与 Kannan 嵌入建模

**关键观察：** 输入数据给出了模数 `q = 7681` （NTT 友好素数， `7681 = 30 * 256 + 1` ）、维度 `n = 32` 、样本数 `m = 64` 、矩阵 `A` （64 行 32 列）和向量 `b` （64 维）。在有限域 `Z_q` 上直接对前 32 行高斯消元得不到有意义的短向量，说明方程含有小噪声项 `e` ，满足 LWE 关系：

```
b ≡ A * s + e (mod q)
```

**原理与操作：** 将同余式展开为整数线性关系，存在整数向量 `k ∈ Z^m` 使得：

```
A * s - b + q * k = -e
```

当 `s` 和 `e` 的分量绝对值远小于 `q = 7681` 时，可通过 Kannan 嵌入构造 `(m + n + 1) × (m + n + 1) = 97 × 97` 的行格基矩阵 `B` （取嵌入权重 `W = 1` ）：

```
B = [ q * I_m    0      0 ]
    [   A^T     I_n     0 ]
    [  -b^T      0      1 ]
```

对于整数行系数向量 `(k, s, 1)` ，其与格基矩阵 `B` 相乘生成的格向量为：

```
v = (k, s, 1) * B = (q * k + A * s - b, s, 1) = (-e, s, 1)
```

该格包含的格点体积为 `det(B) = q^m = 7681^64` 。根据高斯启发式，97 维格中最短非零向量的期望欧氏范数约为：

```
GH(B) ≈ sqrt(97 / (2 * pi * e)) * 7681^(64 / 97) ≈ 2.382 * 365.45 ≈ 870.5
```

而目标短向量 `v = (-e, s, 1)` 在小秘密和小误差条件下的欧氏范数上限低于 `sqrt(64 + 32 + 1) ≈ 9.85` ，远小于高斯启发式下界 `870.5` ，因此 LLL 格基约减可直接分离出唯一目标短向量。

**本步结果：** 完成 97×97 维整数格基矩阵 `B` 的建模，目标向量形式确定为 `v = (-e_0, ..., -e_63, s_0, ..., s_31, ±1)` 。

### 3.2 执行 LLL 格基约减恢复秘密向量与误差向量

**关键观察：** 对 97×97 格基矩阵 `B` 执行标准 LLL 约减后，检查末位坐标绝对值为 `1` 的行向量。

**原理与操作：** 使用 `fpylll` 构造 `IntegerMatrix(97, 97)` 并调用 `LLL.reduction(B)` 。约减完成后，第 0 行（最短基向量）的末位分量 `B[0, 96]` 恰好为 `±1` 。设 `sign = B[0, 96]` ，则可按如下关系提取 `e` 与 `s` ：

```
e[i] = -sign * B[0, i]       (0 <= i < 64)
s[j] =  sign * B[0, 64 + j]  (0 <= j < 32)
```

将提取出的 `s` 和 `e` 代回全部 64 个样本方程检验 `(sum(A[i][j] * s[j]) + e[i]) % 7681 == b[i]` 。

**本步结果：** LLL 约减直接给出真实中间值（欧氏范数为 `sqrt(39 + 14 + 1) = sqrt(54) ≈ 7.35` ），且 64 个方程校验全部通过：


其中秘密向量 `s` 为严格二元向量（元素属于 `{0, 1}` ，汉明重量为 14），误差向量 `e` 为严格三元小误差向量（元素属于 `{-1, 0, 1}` ）。

### 3.3 派生 SHA-256 掩码密钥流还原明文 Flag

**关键观察：** `masked_update` 的长度为 28 字节（ `7c53ddbd82faf811c0397982909a9498644d63fb50a6e697d7cf97f6` ），小于等于 SHA-256 的 32 字节输出长度；同时恢复出的 `s` 为 32 个取值在 `{0, 1}` 的整数组成的列表，恰可直接转换为 32 字节序列 `bytes(s)` 。

**原理与操作：** 将 32 维二元向量 `s` 转换为 32 字节流 `bytes(s)` （即每个分量作为单字节 `\x00` 或 `\x01` ），计算其 `SHA-256` 二进制摘要作为掩码密钥流 `keystream` ，再与 28 字节的 `masked_update` 逐字节异或：

```
keystream = SHA256(bytes(s))
plaintext = masked_update XOR keystream[0:28]
```

| `SHA256(bytes(s))[:28].hex()` | `1a3fbcdaf9979962ab660ae7f5fecbfe16220ea434d489e7b8bae38b` |
| `masked_update` | `7c53ddbd82faf811c0397982909a9498644d63fb50a6e697d7cf97f6` |

客户端每行提交一个十六进制密文，只可能收到 `ok` 或 `bad` 。填充、密文和乘数由 `pad_message` 、 `new_session` 、 `first_conforming_multiplier` 生成：

```python
def pad_message(message, k):
    ps_len = k - 3 - len(message)
    ps = bytearray(secrets.token_bytes(ps_len))
    for i, byte in enumerate(ps):
        if byte == 0:
            ps[i] = 1 + secrets.randbelow(255)
    return int.from_bytes(bytes((0x00, 0x02)) + bytes(ps) + b"\x00" + message, "big")

def new_session(dec, message):
    m = pad_message(message, dec.k)
    c = pow(m, dec.e, dec.n)
    s = first_conforming_multiplier(m, dec.n, dec.k)
    return c, s

def first_conforming_multiplier(m, n, k):
    B = 1 << (8 * (k - 2))
    s = (n + 3 * B - 1) // (3 * B)
    acc = (m * s) % n
    whilenot is_pkcs1_v15(acc, k):
        s += 1
        acc += m
        if acc >= n:
            acc -= n
    return s
```

因此首行 `session <c_hex> <s>` 的含义是：

-   `c = m^e mod n`
    
-   `m` 是本连接的填充块，flag 原文不变， `PS` 每次重抽
    
-   `s` 是从 `ceil(n / (3B))` 往上找到的第一个整数，使 `(m * s mod n)` 也通过填充检查
    

填充检查是完整的 type 2，不只看前两个字节：

```python
def is_pkcs1_v15(m, k):
    em = m.to_bytes(k, "big")
    if em[0] != 0x00 or em[1] != 0x02:
        return False
    i = 2
    while i < k and em[i] != 0:
        i += 1
    return 10 <= i < k
```

`em[0:2] == 00 02` ，从下标 2 起至少 8 个非零字节，并且在块结束前出现分隔 `00` 。断开连接后 `PS` 会变，必须在同一条连接里做完所有查询。

## 2\. 解题思路

这是 Bleichenbacher 的 PKCS#1 v1.5 选择密文攻击。私钥不需要。预言机回答“解密结果是否像一条合法 type 2 块”。

记 `B = 2^{8(k-2)} = 2^{2032}` 。以 `00 02` 开头的 `k` 字节整数正好落在 `[2B, 3B)` 。对已知密文 `c = m^e mod n` ，提交

```
c' = c * s^e mod n
```

服务端解密得到的是 `m * s mod n` 。若回答 `ok` ，则这个值落在 `[2B, 3B)` ，并且还满足 PS 条件。所有仍可能的 `m` 因此被切成若干整数区间。反复寻找新的合法乘数，区间宽度大约每次减少 1 bit，直到只剩一个整数。

服务端已经把第一步乘数 `s1` 算好并下发，本地不必从 `ceil(n / (3B))` 开始盲搜。对这份模数，这个起点是 `17612` ，随机乘数落入 `[2B, 3B)` 的概率约为 `B/n ≈ 1/52835` 。跳过这一段，后面大约两千次成功收窄就能定出明文。

最后检查 `m^e ≡ c (mod n)` ，再按 `00 02 || PS || 00 || flag` 去掉填充。

## 3\. 解题过程

### 3.1 把 ok 翻译成区间 \[2B, 3B)

`k = 256` 字节的块如果以 `00 02` 开头，写成整数就是

```
m = 2 * 256^{254} + t = 2B + t,  0 <= t < B
```

所以 `2B <= m <= 3B - 1` 。反过来，落在这个范围内的整数，其 256 字节大端表示一定以 `00 02` 开头。

`is_pkcs1_v15` 还要求前 8 个填充字节非零，并且后面某个位置有 `00` 。因此：

-   回答 `ok` 可以推出 `m' ∈ [2B, 3B)`
    
-   回答 `bad` 不能推出 `m'` 不在这个范围内；大约四成区间内的整数会因为 PS 内部的零字节被拒绝
    

区间更新只在 `ok` 时进行，用 `[2B, 3B)` 做上界是可靠的。被 PS 规则拒绝的乘数直接跳过，换下一个候选。

对本次公钥：

```
B = 2^2032
s_start = ceil(n / (3B)) = 17612
```

第 4 节脚本连上后打印的 `s_start=17612` 就是这个值。它只和 `n` 有关，每条连接都一样。

### 3.2 用下发的 s1 做第一次收窄

设当前仍可能的明文属于若干区间。对乘数 `s` 和整数 `r >= 0` ，条件

```
2B <= m*s - r*n <= 3B - 1
```

等价于

```
ceil((2B + r*n) / s) <= m <= floor((3B - 1 + r*n) / s)
```

旧区间 `[a, b]` 上需要考虑的 `r` 是

```
r_min = ceil((a*s - 3B + 1) / n)
r_max = floor((b*s - 2B) / n)
```

每个 `r` 和 `[a, b]` 求交，再把相邻区间合并。真实的 `m` 只要确实让 `m*s mod n` 落在 `[2B, 3B)` ，就一定留在新集合里。

首行给出的 `s1` 已经保证 `(m * s1 mod n)` 通过完整填充检查，所以它必然落在 `[2B, 3B)` 。本地用 `c * s1^e mod n` 再问一次预言机，只是确认这条连接和公钥匹配。确认之后直接对初始区间 `[2B, 3B - 1]` 做上面的交。

本次复现连接的首行给出 `s1 = 44949` ，密文 2047 bit。确认查询返回 `ok` 后，区间集合收成 1 段，宽度的比特数是 2017：

```
k=256 s_start=17612 s1=44949 c_bits=2047
after_s1 intervals=1 width_bits=2017 queries=1
```

宽度和乘数的大小相符。一次成功乘法把长度约 `B` 的区间缩成约 `B/s` ：

```
log2(44949) ≈ 15.46
log2(B / s1) = 2032 - 15.46 = 2016.54
```

`2^2016.54` 的比特长度是 2017，与输出一致。

`s1` 更大时，同一次交可能留下多段。另一条连接上服务端给出 `s1 = 131612` ，首次收窄后是 3 个区间、宽度 2015 bit；脚本里的 `find_s_multi` 负责这种情形。它不从 `s+1` 逐个去问（命中率只有约 `1/52835` ），而是对每个区间生成下一个有可能映入 `[2B, 3B)` 的乘数，只问这些候选里最小的一个。那条连接最终也得到了同一个 flag，共用 8070 次查询。下面的复现输出是 `s1 = 44949` 这一次，第一步之后已经只剩单区间。

### 3.3 单区间时让乘数大约翻倍

只剩 `[a, b]` 时，按 Bleichenbacher 的 step 2c 选下一组候选，而不是继续取最小的 `s` 。最小乘子往往只把区间削掉一点，查询次数会从线性变成按比特线性。

取

```
r >= ceil(2 * (b*s_prev - 2B) / n)
```

再在

```
s ∈ [ceil((2B + r*n) / b), floor((3B - 1 + r*n) / a)]
```

里向预言机询问。这样得到的 `s` 大约至少是 `2 * s_prev` ，新区间长度大约减半，未知比特大约减 1。某个 `r` 的整段候选都被 PS 规则拒绝时， `r` 加 1 继续。

本次连接的日志和“每次成功大约减 1 bit”一致：

```toml
step=1    width_bits=2017  queries=1
step=400  width_bits=1616  queries=1520
step=800  width_bits=1214  queries=3177
step=1200 width_bits=814   queries=4541
step=1600 width_bits=416   queries=5964
step=2000 width_bits=14    queries=7482
```

从 step 1 到 step 400，宽度从 2017 降到 1616，399 次成功收窄去掉 401 bit。step 2000 时还剩 14 bit，随后区间变成单点。全程 7521 次预言机查询，平均每次成功收窄大约 3.7 次往返；多出来的查询就是落进 `[2B, 3B)` 但没通过 8 字节 PS 检查的乘数。

区间上下界相等时，该整数就是候选明文。RSA 加密是双射，再用原始密文核对：

```
pow(m, e, n) == c
```

脚本打印 `reencrypt_ok` ，说明这个块不是“某个看起来合法的填充块”，而是本连接密文的唯一原像。

### 3.4 去掉 type 2 填充

256 字节大端编码后，布局是

```
00 02 || PS || 00 || flag
```

`PS` 的每个字节都非零，所以从下标 2 起遇到的第一个 `00` 就是分隔符。分隔符后面的字节就是 flag。本次解出的 ASCII 字符串是

```
flag{DTAW6tuCFbAKt1FiUIYOqSO9V4U71f9EOOQuNlJu}
```

## 4\. 完整解题脚本

把下面的代码保存为 `solve_pkcs.py` 。模数和指数已经写在脚本里，不读取本地 `pubkey.json` 。主机和端口是本次实例；换实例时只改 `HOST` 和 `PORT` 。

```python
def ceildiv(a, b):
    return (a + b - 1) // b


def merge_intervals(intervals):
    ifnot intervals:
        return []
    intervals = sorted(intervals)
    merged = [list(intervals[0])]
    for a, b in intervals[1:]:
        if a <= merged[-1][1] + 1:
            merged[-1][1] = max(merged[-1][1], b)
        else:
            merged.append([a, b])
    return [(a, b) for a, b in merged]


def narrow(intervals, s, n, B):
    """Keep every m still inside some interval with (m*s mod n) in [2B, 3B)."""
    out = []
    for a, b in intervals:
        rmin = ceildiv(a * s - 3 * B + 1, n)
        rmax = (b * s - 2 * B) // n
        if rmax < 0:
            continue
        if rmin < 0:
            rmin = 0
        for r in range(rmin, rmax + 1):
            na = max(a, ceildiv(2 * B + r * n, s))
            nb = min(b, (3 * B - 1 + r * n) // s)
            if na <= nb:
                out.append((na, nb))
    return merge_intervals(out)


class Scanner:
    """Next multipliers that can send [a, b] into [2B, 3B)."""

    def __init__(self, a, b, s_min, n, B):
        self.a, self.b, self.n, self.B = a, b, n, B
        self.s_min = s_min
        self.r = max(0, ceildiv(a * s_min - 3 * B + 1, n))
        self.cur = None
        self.high = None
        self._advance()

    def _advance(self):
        a, b, n, B = self.a, self.b, self.n, self.B
        for _ in range(2_000_000):
            low = ceildiv(2 * B + self.r * n, b)
            high = (3 * B - 1 + self.r * n) // a
            if high < self.s_min:
                new_r = ceildiv(a * self.s_min - 3 * B + 1, n)
                self.r = self.r + 1if new_r <= self.r else max(new_r, 0)
                continue
            start = max(low, self.s_min)
            if start <= high:
                self.cur, self.high = start, high
                return
            self.r += 1
        raise RuntimeError("no candidate multiplier")

    def pop(self):
        s = self.cur
        self.s_min = s + 1
        if s < self.high:
            self.cur = s + 1
        else:
            self.r += 1
            self._advance()
        return s


def find_s_multi(intervals, s_prev, n, B, oracle):
    scanners = [Scanner(a, b, s_prev + 1, n, B) for a, b in intervals]
    whileTrue:
        s_try = min(sc.cur for sc in scanners)
        if oracle(s_try):
            return s_try
        for sc in scanners:
            if sc.cur == s_try:
                sc.pop()


def find_s_single(a, b, s_prev, n, B, oracle):
    """Bleichenbacher step 2c: choose r so s roughly doubles."""
    r = max(0, ceildiv(2 * (b * s_prev - 2 * B), n))
    whileTrue:
        low = max(s_prev + 1, ceildiv(2 * B + r * n, b))
        high = (3 * B - 1 + r * n) // a
        if low <= high:
            for s in range(low, high + 1):
                if oracle(s):
                    return s
        r += 1


class CountingOracle:
    def __init__(self, fn):
        self.fn = fn
        self.queries = 0

    def __call__(self, s):
        self.queries += 1
        return self.fn(s)


def attack(n, e, c, s1, oracle, k):
    B = 1 << (8 * (k - 2))
    intervals = narrow([(2 * B, 3 * B - 1)], s1, n, B)
    ifnot intervals:
        raise RuntimeError("s1 produced an empty interval set")
    width = max(b - a for a, b in intervals).bit_length()
    print(f"after_s1 intervals={len(intervals)} width_bits={width} queries={oracle.queries}", flush=True)
    s = s1
    step = 0
    t0 = time.time()
    whileTrue:
        step += 1
        if len(intervals) == 1and intervals[0][0] == intervals[0][1]:
            m = intervals[0][0]
            if pow(m, e, n) != c:
                raise RuntimeError("recovered block does not re-encrypt to c")
            print("reencrypt_ok", flush=True)
            return m
        if step == 1or step % 400 == 0or len(intervals) != 1:
            width = max(b - a for a, b in intervals).bit_length()
            print(
                f"step={step} intervals={len(intervals)} width_bits={width} "
                f"queries={oracle.queries} elapsed={time.time() - t0:.1f}s",
                flush=True,
            )
        if len(intervals) == 1:
            a, b = intervals[0]
            s = find_s_single(a, b, s, n, B, oracle)
        else:
            s = find_s_multi(intervals, s, n, B, oracle)
        intervals = narrow(intervals, s, n, B)
        ifnot intervals:
            raise RuntimeError("interval set became empty")


class Remote:
    def __init__(self, host, port):
        ctx = ssl.create_default_context()
        ctx.check_hostname = False
        ctx.verify_mode = ssl.CERT_NONE
        raw = socket.create_connection((host, port), timeout=20)
        raw.setsockopt(socket.IPPROTO_TCP, socket.TCP_NODELAY, 1)
        raw.setsockopt(socket.SOL_SOCKET, socket.SO_KEEPALIVE, 1)
        self.s = ctx.wrap_socket(raw, server_hostname=host)
        self.s.settimeout(60)
        self.buf = b""

    def readline(self):
        whileb"\n"notin self.buf:
            chunk = self.s.recv(8192)
            ifnot chunk:
                raise EOFError("connection closed")
            self.buf += chunk
        line, self.buf = self.buf.split(b"\n", 1)
        return line

    def query(self, c):
        self.s.sendall(b"%x\n" % c)
        line = self.readline()
        if line == b"ok":
            returnTrue
        if line == b"bad":
            returnFalse
        raise RuntimeError(f"unexpected reply {line!r}")

def unpad(m, k):
    em = m.to_bytes(k, "big")
    if em[:2] != b"\x00\x02":
        raise RuntimeError("missing 00 02 prefix")
    sep = em.index(b"\x00", 2)
    if sep < 10:
        raise RuntimeError("PS shorter than 8 bytes")
    return em[sep + 1 :]
```
