## 知识库洞察

-   **政府数据集中泄露**：印尼、菲律宾、厄瓜多尔、墨西哥政府站点同日被点名，符合近期“东南亚/拉美政府门户系统暴露”趋势；此类站点常见漏洞为未授权 API 访问与备份文件公网暴露。
    
-   **UNC6783**：知识库标注为针对政府与网络安全机构的中等规模 APT 类团伙，偏好窃取内部文档后整包出售。
    
-   **KYC 数据黑市化**：印度 CredRight 22GB KYC（照片/视频/录音）显示金融科技外包与数字借贷平台成为高价值目标。
    

## 防护建议

-   **政府机构**：排查 `.gob.ec/.go.id/.gov.ph` 类门户的备份文件与 API 鉴权；对国民身份证号等字段实行加密与最小化采集。
    
-   **金融与航空业**：对 KYC 影像资料启用加密存储与访问审计；监控论坛中自身域名的售卖帖。
    
-   **通用**：订阅 Telegram/暗网售卖帖监控，建立“泄露声明→真实性核验→客户通报”的 72 小时响应流程。
