02项目介绍

ApolloFish（阿波罗安全风险演练平台）是一款通过模拟真实网页钓鱼、邮箱钓鱼场景，帮助企业 **检验员工安全防护能力** 的开源演练平台。

做过安全意识培训的人都懂：

年年念 PPT、发手册，员工到底会不会中招没人知道；想搞一次钓鱼演练，得自己搭站点、写邮件、配 SMTP、手工统计上钩名单，一套流程下来比真攻击还累。

ApolloFish 把这些全流程整合了：以 **实战化演练** 替代说教式培训，1:1 还原真实钓鱼攻击场景，全流程行为数据追踪 + 多维度分析，自动生成企业全员安全意识评估报告，精准定位各部门、各层级的防护短板，并基于演练结果推送个性化培训内容。

**一句话概括：从模板制作、站点搭建、邮件投递到上钩统计、报告导出全流程开箱即用，无需专业红队，安全部门自己就能组织一场完整的钓鱼演练。**

03核心亮点

🎣 网页钓鱼演练：内置常见钓鱼页面模板，支持自定义 HTML 模板，自动记录页面中所有 input 参数，创建站点即可对外访问🌐 站点灵活可控：支持自定义端口、IP / 域名访问，支持配置 HTTPS 证书加密访问📧 邮箱钓鱼演练：邮件模板 + 附件模板管理，SMTP 一键测试，收件人批量导入，发送状态可查、失败可重发📊 上钩记录追踪：网页侧完整记录用户提交的信息（JSON 存储），邮箱侧可通过无害化演示附件回传运行状态🤖 AI 生成模板：对接 DeepSeek 等大模型，输入网站名称和生成词即可产出钓鱼页面模板，一键应用编辑⚡ 极简部署：无需 Docker、无需复杂依赖，单文件跨平台运行，首启自动生成随机后台路径与账号密码

04部署与使用

无需 Docker 环境、无需复杂依赖， **单文件直接运行**，覆盖 Windows / macOS / Linux 的 x86 与 ARM 架构，鲲鹏、海光等国产信创环境同样支持。

首次运行自动生成 config.yaml，随机分配后台路径与登录账号密码；1.0.10 版本起首次部署只需确认使用授权、导入离线激活文件即可投入使用，从下载到开演基本零门槛。

**核心理念：安全意识不是念出来的，是"钓"出来的——让员工在可控的演练里暴露短板，好过在真实的攻击里付出代价。**
