三、ARTEX部署

运行安装程序前，需要先部署 PostgreSQL。

![图片](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/648894ecc8cfdd1d.png)

根据自身操作系统版本，选择对应的安装包下载。

![图片](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/1d26f3516d90b56e.png)

进入项目目录，复制 config.example.json，并将副本重命名为 config.json，并配置数据库密码。

![图片](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/4a1142e2e8edcbe9.png)

ARTEX强依赖PostgreSQL存储任务、资产、流量日志，没有数据库直接反复崩溃重启，需要执行以下命令。

```bash
sudo -u postgres psql
CREATE USER artex WITH PASSWORD 'artex123456';
CREATE DATABASE artex OWNER artex;
GRANT ALL PRIVILEGES ON DATABASE artex TO artex;
\q
```

![图片](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/3b8093aea7bfcfdd.png)

PostgreSQL 默认端口为 5432，请记得修改 config.json 里的数据库端口配置。

![图片](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/96c43b139206105e.png)

![图片](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/53934b71f256e268.png)

执行下面的命令，启动ARTEX服务。

```nginx
bash start.sh -addr 0.0.0.0:8787 -proxy 0.0.0.0:8788
```

![图片](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/642b7c5964674eb7.png)

首次登录时，初始化令牌填写控制台内的 token，并设置登录密码。

![图片](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/f091264fc82110fd.png)

![图片](https://cdn.jsdelivr.net/gh/zhiyu-zeng/img@main/img/2026/11/d262801618db6a61.png)

修改skills目录，否则无法加载skills。
