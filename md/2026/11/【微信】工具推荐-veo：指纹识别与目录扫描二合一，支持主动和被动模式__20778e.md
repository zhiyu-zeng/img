> TL;DR：veo 是一款将指纹识别与目录扫描合二为一的开源资产测绘工具，支持主动与被动两种模式，攻防双方均可用它测绘目标暴露面。
> 
> - **核心功能：** 集成指纹识别与目录扫描，项目地址为 github.com/neouks/veo；提供 darwin_arm64 / linux_amd64 / windows_amd64 三个平台的 release 包，被动扫描首次使用需解压 ca-cert.zip 安装证书。
> - **常用用法：** `-u` 扫单目标、`-l` 批量扫描、`-w` 自定义字典 + `-o` 实时 CSV 报告、`--depth` 递归扫描、`-m finger / -m dirscan` 切换纯指纹或纯目录模式、`--listen -lp 8090` 启动被动监听，支持 `*.baidu.com`、`10.0.0.*` 等通配目标。
> - **无效页面过滤链：** 依次经过状态码白名单（默认 200/301/302/401/403/405/500）、静态资源 Content-Type 过滤、主哈希过滤（阈值 3）、二次哈希去重（阈值 1）、相似页面容错（默认 50 字节），均可配置覆写。
> - **认证头探测：** 遇到 401/403 响应会自动提取认证信息并携带认证继续扫描，可发现更多有效路径；指纹识别环节支持解压 gzip/deflate/brotli 并执行 DSL 规则输出匹配结果。
> - **攻防启示：** 被动监听模式意味着流量经过即可识别资产，敏感单位应排查网络出口是否存在未授权流量镜像；防守方可定期自查后台、接口暴露面，并重点核查受认证保护目录是否存在弱口令或越权。

一、工具简介

veo 是一款支持 **指纹识别** 与 **目录扫描**、同时支持主动与被动模式的工具。项目地址：github.com/neouks/veo。

二、支持平台与快速上手

可在 release 中下载，支持 veo_darwin_arm64.tar.gz、veo_linux_amd64.tar.gz、veo_windows_amd64.zip。运行 veo.exe -h 查看帮助；被动扫描时首次使用请解压 ca-cert.zip 安装证书。常用命令包括：默认配置目录扫描 + 指纹识别（./veo -u http://target.com）、批量目录扫描 + 指纹识别（./veo -l target.txt --stats）、使用自定义字典并输出实时 CSV 报告（-w dict/custom.txt -o report.csv）、递归目录扫描（--depth 2）、禁用哈希过滤（--no-filter）、自定义状态码过滤（-s 200,301,302,403）、仅指纹识别（-m finger）、仅目录扫描（-m dirscan）、显示指纹匹配规则与匹配片段（-vv）、自定义 HTTP 头部（--header）、控制台输出 JSON（-j）、更新指纹识别规则库（--update-rules）、被动扫描（--listen -lp 8090，支持./veo -u \*.baidu.com --listen -lp 8090 与./veo -u 10.0.0.\* --listen -lp 8090）。

三、目录扫描无效页面过滤逻辑

① **状态码过滤**：默认白名单 200/301/302/401/403/405/500，可覆写。② **静态资源过滤**：根据 Content-Type / 扩展名排除图片、视频等页面。③ **主要哈希过滤**：剔除重复或异常页面，默认阈值 3。④ **二次哈希过滤**：对相似页面去重，默认阈值 1。⑤ **相似页面容错**：默认 50 字节，可通过配置文件或 SDK 参数调整。⑥ **认证头探测**：对 401/403 响应自动提取认证信息、携带认证扫描，出货率更高。⑦ **指纹识别**：解压 gzip/deflate/brotli、自动识别编码，执行 DSL 规则，输出 <rule_name> 与 <rule_content>。

情报价值：veo 把"指纹识别 + 目录扫描"整合进单一工具并支持被动监听，是一款典型的攻防两用资产测绘工具。对网安工作的启示：一是资产测绘是攻击面管理与攻击溯源的基础——防守方可用其定期自查暴露面（默认字典 + 状态码白名单帮助快速定位后台、接口与静态资源），攻击方则用于踩点，双方能力同源；二是"被动扫描（监听端口 9080/8090）"模式意味着流量经过即可被动识别资产，提示敏感单位须关注网络出口是否存在未授权的流量镜像/被动探测节点；三是其"认证头探测 + 401/403 自动携带认证"逻辑，反映后台暴露面排查的实战要点，资产梳理时应重点核查受认证保护的目录是否存在弱口令或越权。
