**设备堆了一机房，为什么还是被打穿**

**01**

做过政务安全项目的人都有这个感受：防火墙、WAF、IDS、EDR、态势感知买了一堆，结果一封钓鱼邮件还是能打进来。等保过了，攻防演练还是被打穿。

问题不在设备不够多，而在 **防护思路还停留在边界防御时代**——默认内网是安全的。但攻击者根本不跟你在边界硬碰硬，走的是人→终端→内网→横向→核心数据的路径，每一步都在利用你的内部信任。

**攻击者视角：打穿一个政务单位分几步**

**02**

|     |     |     |
| --- | --- | --- |
| 阶段  | 常见手法 | 利用的薄弱点 |
| 侦察踩点 | 子域名爆破、端口扫描、Github信息泄露、招标信息分析 | 暴露面管理缺失，敏感信息泄露 |
| 初始突破 | 鱼叉钓鱼+宏载荷、水坑攻击、VPN/OA漏洞利用、弱口令爆破 | 人员意识不足，对外系统补丁滞后 |
| 权限提升 | 本地提权漏洞（如CVE-2021-40449）、Mimikatz抓取哈希、服务配置错误 | 终端补丁不到位，本地管理员权限过大 |
| 内网横向 | Pass-the-Hash、SMB漏洞（永恒之蓝类）、RDP爆破、域控漏洞（Zerologon） | 内网缺乏分段，域架构薄弱，口令复用 |
| 目标达成 | 数据窃取外发、勒索加密、植入后门、网页篡改 | 数据未分级，外发无检测，备份不完善 |

这个链路里， **任何一个环节卡住，攻击就会失败或成本大增**。但多数单位是边界强、内网弱、终端散、数据裸奔，攻击者一旦进来基本就是横走。

**5个关键防护点，多数单位没做到位**

**03**

**一、攻击面收敛——先把门关小。**

很多单位自己的对外暴露面都不清楚：子域名、测试系统、废弃端口、管理后台直接暴露公网。攻击者用FOFA一搜比你资产清单还全。该做的：每季度做资产梳理和暴露面检测；管理后台（SSH/RDP/数据库）禁止直接暴露公网，必须走VPN或堡垒机；边界设备固件补丁跟紧，很多演练入口就是VPN已知漏洞；Github/码云搜一下单位名称，经常能搜到误传的配置和源码。

**二、终端加固——最薄弱的环节在桌面上。**

政务终端数量多、系统杂（还有大量Win7）、补丁推不动。该做的：用EDR替代传统杀毒，传统杀毒靠特征码对免杀和无文件攻击基本无效，EDR基于行为能发现可疑PowerShell和横向探测；关键漏洞72小时内修复，Win7等停服系统要么升级要么做隔离+应用白名单；普通用户不给本地管理员权限；核心终端启用AppLocker白名单——勒索病毒再厉害，跑不起来就没用。

**三、内网分段——别让攻击者进来就横走。**

最普遍的问题：内网一个大二层，办公网、业务网、服务器网全混在一起，VLAN划了但ACL全通。该做的：按安全等级分区（互联网区/DMZ/办公区/业务区/数据区/运维区），区间默认拒绝按需放通；域控、数据库、核心服务器放独立安全域，只允许特定IP访问；在内网核心做流量镜像，部署NDR监控东西向异常流量——很多单位只看南北向，对内网横向完全失明；域控及时打补丁，禁用NTLMv1，管理员账号和普通账号分离。

**四、身份与访问管理——零信任不是口号。**

政务系统账号多、权限乱：调岗了权限还在，离职了账号没禁用，运维用个人账号登生产。该做的：账号全生命周期管理和人事流程打通，每季度审计清理僵尸账号；VPN、堡垒机、核心系统、邮箱必须上MFA，这一条能挡住90%以上的弱口令爆破；所有运维操作必须走堡垒机，禁止直连，做命令审计和录像；不必一上来搞完整零信任，先做到任何访问都要认证授权，内网外网一个标准。

**五、数据安全与备份——最后一道防线不能崩。  
**

很多单位数据裸奔：数据库没加密、备份和生产同机房、敏感文件随便共享。该做的：先做数据分类分级，核心数据（个人信息、政务数据、未公开文件）加密存储+访问审计+外发审批；严格执行3-2-1备份（3份副本、2种介质、1份异地/离线），备份系统和生产网络隔离、账号独立，定期做恢复演练——很多单位备份做了但从没恢复过，真出事才发现备份是坏的；数据库账号最小权限，禁用sa/root默认账号；通过DLP或邮件网关监控含身份证号、手机号的文件外发。

**让防护体系活起来**

**04**

设备买了不代表安全了，很多单位的安全设备是聋子的耳朵——告警天天有但没人看。该做的：建立告警分级处置流程，不能全靠厂商驻场；每年至少一次渗透测试，等保是合规视角，渗透是攻击视角，不能互相替代；每季度做内部钓鱼演练，成本最低效果最明显；每年做一次勒索/数据泄露应急演练；接入CNVD/CNNVD威胁情报，关注政务行业最新漏洞。

政务安全是一场不对称战争——攻击者只需一个突破口，防守方要守住所有面。但把攻击面收敛好、终端加固做扎实、内网分段别偷懒、身份管理严一点、数据备份别马虎，再加上持续运营，攻击者的成本会指数级上升，大多数时候他们会换个更容易的目标。

**安全没有银弹，但有方法论。从攻击视角看防护，比从合规视角堆设备，有用得多。**
