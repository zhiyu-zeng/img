## Ubuntu配置教程

开发经常要在Linux环境下搞项目，因此很有必要弄一台Ubuntu虚拟机

## 文件共享解决方案

Windows端使用MobaXterm + Ubuntu端使用SSH

```
sudo apt-get install ssh openssh-server
PGSQL
```

查看一下ip地址

```
ifconfig
EBNF
```

MobaXterm直接SSH连接就行了

## 代理解决方案
