一个缺少边界的模板参数，如何变成 getshell

## 漏洞成因

问题代码位于工具站的 /application/index/controller/index.php。核心逻辑可以简化为：

存在缺陷的控制器逻辑 · 已省略无关分支

public function index()

{

$data = array();

$act = input('act', 'index');

switch ($act) {

// 已有分支，没有默认兜底

}

return $this->fetch($act, $data);

}

switch 没有默认分支，用户传入的 act 最终仍可能进入 fetch()，被当成模板名处理。当对应模板不存在时，程序报错，并把用户输入原样写入运行时日志；攻击者随后又让日志文件进入模板编译流程，使其中内容被执行。
