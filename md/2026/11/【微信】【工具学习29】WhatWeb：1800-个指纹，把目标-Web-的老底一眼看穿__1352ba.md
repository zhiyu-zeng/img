WhatWeb：1800 个指纹，把目标 Web 的老底一眼看穿

单个站点的渗透，最忌讳的就是一上来就莽。真正有章法的人，动手之前总要先在心里问一句： **对面的网站到底是用什么搭的？** 是 WordPress 还是自研框架？跑在 Nginx 还是某个更冷门的服务器上？用了哪个版本的组件？这些问题一旦有了答案，后面每一步——找已知漏洞、选攻击面、决定先打哪里——就都有了方向。而这个问题，正是 WhatWeb 的专长。

它给自己的定位是"下一代 Web 扫描器"，Ruby 写的。它不干别的，就专注一件事： **识别一个网站的技术栈**。CMS、博客平台、JavaScript 库、Web 服务器、框架、甚至嵌入式设备，它都认得，顺带连版本号、SQL 报错、账号 ID 这类细枝末节也给你扒出来。

## 指纹识别原理

它是靠什么"看穿"的

你去逛一个网站，浏览器发出的请求、网站回的数据里，其实藏着一堆技术痕迹：响应头的 `X-Powered-By` 、设置的 cookie 名、页面里的 meta 标签、 `/wp-content/` 这类固定路径、甚至一个 favicon 图标，都在默默暴露技术栈。单独一条线索可能不明显，但 WhatWeb 是把这些线索 **聚合起来综合判断**，可靠性就上来了。

比如识别 WordPress，它一个插件就有 15 项测试：check meta 标签、favicon、默认安装文件、登录页、链接里的路径……不是只看一两个特征，而是交叉验证。这就是它厚实的地方——手里攥着 **1800 多个插件**，每一个都针对某种特定技术做了多角度识别。

## 基础用法

用法简单到几乎不用学

最基本的，直接把目标丢给它：

whatweb example.com

它会自动测 HTTP 和 HTTPS 两种协议，返回一长串识别结果。别被那串字符吓到，其实都在交代信息： `HTTPServer` 告诉你什么服务器、 `Cookies` 拿到设置了哪些 cookie、 `Title` 是页面标题、 `X-Powered-By` 直接点破用了什么语言或框架，还有 `Country` 、 `IP` 这些基础信息。一眼扫过去，这站点的"底子"基本就清楚了。

## 激进档位与隐蔽性

速度和隐蔽性，自己挑

WhatWeb 的特点之一，是它把"快而隐蔽"和"彻底但慢"做成了一条可调节的档位，靠 `-a` 参数控制，也就是它的 **aggression（激进程度）**：

🔹 **level 1（stealthy）**：默认档，每目标只发一个 HTTP 请求，最快最隐蔽，适合扫公开网站。

🔹 **level 3（aggressive）**：会对疑似命中的目标进一步探询，发更多请求拿更准的版本。比如某个网站疑似用 WordPress，level 3 会触发 WordPress 插件里的额外探测，把确切版本挖出来。

🔹 **level 4（heavy）**：对每个目标发大量请求，做最彻底的探测，通常用于渗透测试这种对准确性要求更高的场景。

用三个命令感受下这个梯度：

whatweb example.com  
whatweb -a3 example.com  
whatweb -a4 example.com

档位越高越准，代价是越多请求、越容易被发现。怎么选，看你要隐蔽还是要命中率。

## 批量与定向扫描

不只是单点扫描

它真正好用的地方，是 **批量** 能力。

指定一个网段，直接整段扫，不开 80/443 的无所谓，加 `--no-errors` 屏蔽报错免得刷屏：

whatweb --no-errors 192.168.0.0/24

还要顺手标记哪些是 HTTPS 的？用 `--url-prefix` 统一加前缀：

whatweb --url-prefix https:// 192.168.0.0/24

把目标列表写进文件，用 `-i` 批量读入，配合 `-t` 调整并发线程数，一套下来能把一个大范围资产的指纹快速过一遍。

**定向搜技术** 也很有用。你想找目标里哪些站点跑着 phpBB，不用肉眼翻输出，直接搜：

whatweb -I phpBB

甚至可以用 `--grep` 在页面里搜指定字符串或正则，把它当个轻量的内容匹配器用。想排查目标网络里有没有隐藏的管理后台，这类定向能力能省不少事。

## 渗透链路中的定位

它在渗透链路里的位置

对渗透来说，WhatWeb 填的是"知己知彼"里的"知彼"：它输出的技术栈和版本，直接对接后续动作——知道对方跑的是某框架的某个版本，就去查这个版本有没有公开漏洞；识别出 CMS，就知道默认路径、默认后台、默认密码套路大概在哪儿。它还有个锦上添花的点：所有识别结果能导出成 JSON、XML 甚至直接写进数据库，方便自动化流程接着吃。

对正在搭 Hermes 这种自动化渗透系统的人来说，这个"可喂给下游"的能力很关键：把 WhatWeb 的指纹输出接进判定逻辑，程序就能基于"目标是什么技术栈"自动决定下一步调用哪个漏洞验证模块。它像个勤恳的前哨，把情报送回来，后面怎么打由更大的体系来编排。

**蓝队视角也不吃亏。** 反过来想，凡是你能拿 WhatWeb 一眼看穿的技术栈，攻击者也一样能。所以做防护时，隐藏或混淆那些暴露组件版本的响应头、换掉默认路径、规避特征明显的报错，都是在给自己的技术底细减曝光。少让人"看穿"一分，就多一分从容。
