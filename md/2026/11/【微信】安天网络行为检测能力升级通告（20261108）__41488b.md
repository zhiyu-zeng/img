**安天集团** *2026年11月8日 11:00*

安天长期基于流量侧数据跟踪分析网络攻击活动，识别和捕获恶意网络行为，研发相应的检测机制与方法， 积累沉淀形成了安天自主 创新 的网络行为检测引擎 。 安天 定期发布最近的 网络行为检测能力升级通告 ，帮助客户洞察流量侧的网络安全威胁与近期恶意行为趋势，协助客户及时调整安全应对策略，提升网络安全整体水平。

**01**

**安天 **网络行为检测能力概述****

安天网络行为检测引擎收录了近期流行的网络攻击行为特征。本期新增检测规则55条，本期升级改进检测规则49条，网络攻击行为特征涉及代码执行、代码注入等高风险，涉及漏洞利用、文件上传等中风险。

**03**

**网络流量威胁趋势**

近期，安全研究人员发现名为 LLMJacking 的新型攻击模式，攻击者通过窃取 IAM 凭据、 API 密钥、 GitHub 个人访问令牌、会话令牌获取企业云环境访问权限，不窃取业务数据，目标占用付费大语言模型推理算力，搭建代理中转服务，将窃取的 AI 访问能力在地下市场低价转售，最高可以达到官方定价 97% 折扣。攻击案例分布北美、南美以及亚太地区，单起事件单日产生超过 10 万美元非授权账单，部分受害企业累计账单损失接近 100 万美元。攻击者获取权限后测试模型配额，提升 GPU 硬件配额，部署 LiteLLM 代理、自定义容器镜像，新建高权限服务账号，采用账号用完即弃轮换策略规避速率限制与检测。

此外，研究人员披露 Volta 信息窃取木马新增 AI 研判能力，该恶意程序可窃取浏览器凭证、加密货币钱包助记词、各类平台会话令牌与系统信息，还会利用窃取凭证补充受害者住址、资产等信息。木马可调用外部大模型对收集到的数据开展分析，划分受害者价值等级并评估其安全习惯，生成分析报告。该功能为工具增值模块，支持多模型自动降级切换规避安全限制，采集数据打包后通过 Telegram 通道外传，运行结束后木马本体具备自删除机制。

**值得关注的安全事件**

**1**

**安天发布 [《ARTEX 流行 Fork 镜像供应链投毒事件分析》](https://mp.weixin.qq.com/s?__biz=Mzg5MTU3NTM0Nw==&mid=2247486265&idx=1&sn=bfb92d0f25a33c00f41fe0f5c0f40895&color_scheme=light&scene=21#wechat_redirect) 报告**

**安天 CERT 发布 ARTEX 流行 Fork 镜像供应链投毒事件分析。分析确认，源码包本身不含后门，攻击者通过篡改 docker-compose.yml 镜像引用，将用户导向植入后门的预构建镜像；镜像内二进制在登录接口被植入未认证命令执行逻辑。报告包含样本信息、后门原理、汇编级证据与排查处置建议，供核查参考。 安天 CERT 建议用户凡通过 trhhubsd/ARTEX 仓库部署过 ARTEX 的用户，均应执行检查；已确认拉取或运行过 tomicdd/artex 镜像的主机，应按失陷主机处理。**

**2**

**NetamLoader恶意软件针对亚洲政府Windows设备**

**安全研究人员披露，NetamLoader为一款.NET架构恶意加载器，样本于2026年上半年捕获，载荷封装在CAB更新归档文件中存放至Windows更新目录，滥用AppDomainManager注入技术，依托Patch My PC合法组件执行代码。载荷经过多层XAML与Base64嵌套编码，内置AMSI绕过与痕迹清理逻辑，C2域名为openaigpt4v \[.\] com，样本会延迟20至40分钟发起首次网络请求规避检测。当前仅观测到单台受害主机，样本目标为定制版Windows10系统，相关研究披露该载荷针对政府场景投放。**

**安天探海网络检测实验室简介**

安天探海网络检测实验室是安天科技集团旗下的网络安全研究团队，致力于发现网络流量中隐藏的各种网络安全威胁，从多维度分析网络安全威胁的原始流量数据形态，研究各种新型攻击的流量基因，提供包含漏洞利用、异常行为、应用识别、恶意代码活动等检测能力，为网络安全产品赋能，研判网络安全形势并给出专业解读。
