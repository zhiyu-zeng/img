一、项目导语

攻防演练的胜负，往往在正式攻击开始前就已经决定。红队不需要复杂漏洞，只靠公开情报，一键输入域名，短短10秒，就完成对目标资产的测绘、指纹识别、暴露面梳理。今天我们拆解GitHub热门开源OSINT项目web‑check，看懂攻击者是如何快速扒光网站公开信息，也教会企业如何自查自身暴露风险。

在攻防演练、护网行动的信息收集阶段，很多人以为黑客需要复杂扫描器、海量 POC。但现实是，大量侦查工作依靠开源情报（OSINT）完成。攻击者只需要输入主域名，一键触发检测，10秒拿到 DNS、证书、HTTP 头、开放端口、技术栈、域名注册信息等几十项公开数据，快速绘制攻击面地图。

Web‑Check（GitHub：lissy93/web‑check/35K+Star）就是这样一款爆火的一体化开源 OSINT 工具，GitHub Star 数万，被大量红队、安全研究员、运维人员使用，号称给网站做一次X光扫描。

二、信息收集能力

1️⃣基础网络与域名信息

IP 地址、服务器地理位置、运营商 ASN 信息

完整 DNS 记录：A、AAAA、MX、NS、CNAME、TXT、CAA、DNSSEC 状态

WHOIS 域名注册信息，注册商、注册时间、过期时间

Traceroute 网络路由、同 IP 下关联其他主机资产

2️⃣证书与安全头部检测

SSL/TLS 证书完整链条，有效期、颁发机构、证书异常告警

HTTP 响应头解析：HSTS、CSP、X‑Frame‑Options 等安全头是否缺失

Cookie 属性检测：HttpOnly、Secure、SameSite 等标志位配置

3️⃣站点指纹与业务信息

技术栈识别：Web 服务、CMS、前端框架、第三方组件指纹（基于 Wappalyzer 规则）

robots.txt、sitemap 解析，抓取规则、站点页面清单

完整重定向链路追踪，识别跳转异常

开放常见端口检测、第三方追踪脚本识别

4️⃣辅助安全维度

站点可用性、响应性能评分；

域名是否出现在恶意、钓鱼黑名单；

SPF、DMARC 邮件安全记录校验。

通俗讲：所有浏览器、公网 DNS 对外能泄露的信息，Web‑Check 全部汇总展示。红队在攻防演练里，用它快速摸清目标对外资产边界，寻找潜在突破口。

四、项目使用

提供在线服务与本地私有化部署两种方案，按需选择。

1️⃣本地私有化部署

```nginx
git clone https://github.com/Lissy93/web-check.git  # Download the code from GitHub
cd web-check                                        # Navigate into the project dir
yarn install                                        # Install the NPM dependencies
yarn build                                          # Build the app for production
yarn start                                          # Start the app (API and GUI)
```
