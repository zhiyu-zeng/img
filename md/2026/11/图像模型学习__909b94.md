## 图像模型学习

常用的图像模型有ResNet、Vit之类的

利用预训练好的图像模型以及参数，训练一个图像分类模型，模型示例代码如下：

```python
from timm.models import vit_base_patch16_224_in21k

vit_transform = transforms.Compose([
    transforms.Resize((224,224)),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.5, 0.5, 0.5], std=[0.5, 0.5, 0.5])
])

class ImageClassifier(nn.Module):
    def __init__(self,config:dict):
        super().__init__()
        self.core = vit_base_patch16_224_in21k(pretrained=True,num_classes=0)
        self.fc = nn.Linear(self.core.num_features, 1)
    def forward(self, x):
        features = self.core(x)
        return self.fc(features)
    def freeze_part_swin(self):
        #冻结所有层
        for param in self.core.parameters():
            param.requires_grad = False
PYTHON
```

这里使用了预训练的Vit模型， [https://huggingface.co/google/vit-base-patch16-224-in21k](https://huggingface.co/google/vit-base-patch16-224-in21k)

训练的时候把vit模型参数冻结起来就行了，本质上是利用vit模型提炼出来的特征，训练一个分类器，这里训练的是二分类。

测试下来发现，在预训练模型的强大参数加持下，即便是微量的样本数据集进行训练，也能起到较强的分类效果。

缺点也比较明显，不同业务数据的特征是有较大差异的，这里用实际业务数据进行训练测试，发现模型准确率达到95%左右，就提升不动了，说明无法进一步提炼出图像里面的特征了。
