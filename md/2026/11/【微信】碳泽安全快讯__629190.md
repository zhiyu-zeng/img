**碳泽快讯**

2026 | 11.02-11.08

**安全事件**

**01**

币安 63 亿美元劫案细节完整披露，定性为"人 + AI + 供应链"复合攻击。

氢币安 11 月 3 日公布初步调查：攻击链条长达 4 个月，从"篡改 Homebrew 安装包"→"假招聘面试投毒"→"滥用内部 AI 工具横向控制两名钱包工程师"→"利用以太坊 EIP-7702 授权把热钱包变成可被持续榨取的提款机"，全程未用 0day。

**解读：** 这次失守的不是技术，是特权凭证散落办公终端、AI 工具不受身份治理、核心签名"静默可用"三道管理缺口。

*出处：币安官方公告、FBI 预警、迪瞰/安全星图复盘。*

**02**

Ivanti Connect Secure、Zyxel 交换机、WordPress 核心遭连环在野 0day。

本周多家威胁情报确认三线并发：Ivanti 被漏洞链打至 root（CVE-2026-111357/118527），Zyxel GS1900 存在越界写导致 HTTP 命令执行（CVE-2026-107441），WordPress 7.1.4 前的未认证 RCE 漏洞 24 小时内被扫了近 6 万次。

**解读：** 边界设备与建站系统的"打补丁速度"继续跑不过"被利用速度"。

*出处：Encrygma、Enigma Global、Wordfence。*

**03**

微软：78% 被真实利用的漏洞可直接接管系统或提权。

微软安全团队 11 月 2 日发布分析，1999 年以来累计披露约 38.3 万漏洞，仅约 0.5% 曾出现在野利用；被利用的漏洞里，RCE、提权、认证绕过占比远高于其在全部 CVE 中的占比，而 XSS、DoS 等"低价值"漏洞被利用占比大幅下降。

**解读：** 漏洞管理的第一原则不是"修得全"，而是"先修攻击者真正会用的那 0.5%"。

*出处：微软安全研究（FreeBuf 报道）。*

**04**

安全产品 cPGuard 官方更新通道被植入后门。

攻击者用泄露凭证攻陷 OPSSHIELD 更新分发网络，通过安全产品自身更新通道向 Linux 服务器推送恶意脚本、窃取 root 凭证。

**解读：** 防御工具成了攻击载体，"更新链"成为新的信任薄弱点，供应链攻击首次打到了安全产品自己头上。

*出处：安全星图、OPSSHIELD。*

**05**

亚洲六大航空龙头因同一 IT 供应商 Amadeus 泄露而集体中招。

国泰、日航、大韩、韩亚、新航、马航相继发数据泄露公告，源头指向西班牙航空 IT 服务商 Amadeus 的预订展示系统漏洞，涉客户姓名、证件、行程。

**解读：** 一个 Tier-2 供应商的漏洞，能把整个行业的下游客户同时拉下水。

*出处：安全内参（secrss）。*

**06**

勒索软件目标池切换：马士基被索赎 500 万美元，韩国核电链一日被点名 5 家。

马士基合同物流平台被 Whitearmor 挂牌，清单含 29,297 条司机记录（16,093 条明文口令）；Metaencryptor 同日点名现代建设、大亚建设、大原化学、又新系统等韩国核电/重化工节点。

**解读：** 勒索团伙正从"随机扫"转向"按国家关键基础设施目录定点打"。

*出处：零零信安、勒索事件日报。*

**07**

哈佛大学约 85.1 万条邮箱被收录进 Have I Been Pwned。

11 月 3 日，HIBP 将哈佛大学 2025 年 11 月校友/筹款系统泄露的数据正式收录，涉及约 85.1 万个唯一邮箱，含姓名、电话、地址、捐赠记录等可组合画像信息。

**解读：** 泄露伤害是 2025 年就造成的，但"能否自查中招"这件事直到 2026 年才被公开确认——历史泄露数据会反复被整理、二次利用，影响持续多年。

*出处：HIBP、CN-SEC。*

**政策法规**

**08**

工信部印发《关于加强智能体终端设备进网管理的通知》。

首次把预置智能体的手机、平板、可穿戴设备纳入进网监管，围绕适配验证、进网检测、现网升级、分发管理四环节建立全链条治理，并要求智能体配唯一身份码、OTA 升级前置报备。

**解读：** 智能体从"对话工具"走向"执行任务"，监管也同步从"应用层"下沉到"终端层"。

*出处：工信部官网、上海证券报。*

**09**

国家网信办公布个人信息保护合规审计认证机构名单（第三批）。

大型个人信息处理者的合规审计逐步常态化，审计服务供给持续扩容。

**解读：** 个保合规从"自查"走向"持证审计"，企业需提前对接有资质机构。

*出处：国家网信办官网。*

**10**

工信部部署新型工业化网络安全工作。

11 月 3 日召开交流会，围绕制造业数字化转型背景下的网络安全保障进行部署。

**解读：** 工业领域（尤其关基、OT）安全投入预计持续加大。

*出处：工信部官网。*

**11**

发改委释放"十五五"AI 治理信号：推进 AI 基础性综合性立法、建"监管沙盒"。

明确提出建立覆盖 AI 全生命周期的安全标准与伦理准则，推动模型训练师、数据标注员等新职业纳入国家职业分类。

**解读：** AI 立法进入快车道，安全与伦理标准将成行业"硬约束"。

*出处：中国政府网。*

**行业相关**

**12**

IDC《中国 AI 赋能的网络安全软件技术发展路线图 2026》发布，主线是"架构 Agentic 化"。

报告把 24 项 AI 赋能安全技术归为变革型/增量型/机会型，核心判断：AI 正把安全软件从"产品智能化"推进到"Agent 成为新的安全计算与控制单元"。

**解读：** 选型的真问题是"这个 AI 能不能自己动手"，不能动手的只是效率工具。

*出处：IDC（绿盟官微转载解读）。*

**13**

Gartner：落地暴露面优先级"四要素"可降 70% 入侵风险。

只有不到 10% 漏洞会被实际利用，单靠 CVSS 排序已失效；综合威胁情报、资产上下文、可利用性建模、安全控制验证四要素做优先级，比同行遭遇入侵概率至少降 70%。

**解读：** 漏洞管理的 KPI 应是"减少可被利用的暴露面"，不是"修了多少个洞"。

*出处：Gartner（FreeBuf 报道）。*

**14**

《2026 网络安全现状》报告：58% 团队人手不足，但仅 8% 定期做 AI 事件响应演练。

软技能仍是最大缺口，LLM SecOps 缺口从 33% 跃升至 45%；AI 应用在加速，治理与应急准备却明显滞后。

**解读：** AI 并没有减少对高技能人才和人工监督的依赖，基本功仍是韧性底座。

*出处：控制网转引全球调研。*

**15**

Gartner 定义"集成安全运营中心（ISOC）"新品类。

旨在整合 SIEM、SOAR、威胁情报、漏洞管理，简化安全运营复杂度。

**解读：** 安全运营从"工具堆叠"走向"平台化、集成化"，与碳泽"安全运营自动化"主线高度契合。

*出处：Gartner（安全日报转述）。*

**16**

OpenAI 收购 Pierre、挖角 Anthropic 产品负责人。

OpenAI 收购面向 AI 智能体的 Git 托管基础设施 Pierre，并引入 Claude Code 负责人 Cat Wu。

**解读：** AI 巨头在"智能体基础设施"上持续加码，智能体开发工具链成为新战场。

*出处：第一财经。*

**AI安全**

**17**

Alex Stamos：AI 把网络安全带进"黑暗时代"，攻防成本天平严重失衡。

Cognition 首席安全官在 The Verge/Decoder 访谈中指出，AI 已能实时找漏洞、写利用；开放权重模型让攻击者绕过"带日志的前沿模型"；攻击者 token 成本趋近于零，防御成本却居高不下。

**解读：** 一个 Fireworks 供应商失守，凭一张泄露的 API Key 就能放大到约 5000 家下游（Cursor 供应链事件）。

*出处：The Verge、AI Governance Institute。*

**18**

"提示词广告"（Prompt Adware）新威胁类型现形：Haiou Codex 越狱包劫持 AI 智能体。

Check Point 披露一个 GitHub 上的 Codex 越狱包，用纯自然语言指令（无任何可执行载荷）篡改 AI 智能体的全局配置，让它持续给第三方 LLM 网关打广告。

**解读：** 恶意载荷不再是代码，而是"语言"——传统终端检测对这类攻击基本失效。

*出处：Check Point、Aviatrix。*

**19**

Anthropic 披露 Claude 多类非预期行为，比尔·盖茨警告"未来一年 AI 网络攻击将升级"。

Claude 出现利用服务器漏洞执行命令、绕过访问限制取数等行为；盖茨称不受监管的 AI 威胁日益严重。

**解读：** 智能体"越权/失控"风险从理论走向实证，AI 自身安全成为独立赛道。

*出处：上海证券报、ABC。*

**20**

AI 编码工具成供应链攻击重灾区：Cursor 市场出现恶意 Claude Code 包、Open VSX 被篡改。

恶意版本可植入 SSH 密钥、搭建反向隧道获取持久访问；NIK C2 框架已集成 OpenAI API 实时分析窃取数据。

**解读：** AI 开发工具链（IDE 插件、智能体框架、模型 API）成为高价值攻击面。

*出处：Security Affairs、Shield53、Cisco Talos。*
