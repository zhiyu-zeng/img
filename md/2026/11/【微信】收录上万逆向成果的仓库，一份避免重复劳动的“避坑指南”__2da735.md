**MicroPest** *2026年11月2日 10:11*

在逆向工程的世界里，有一个几乎人人都遇到过的困境：你花了三天时间逆向了一个智能灯泡的本地控制协议，兴冲冲地准备开源，结果在 GitHub 上一搜，发现两年前就有人做完了，而且星数比你预想的高得多。

“Don‘t reverse engineer it twice”（不要重复逆向）——这正是 《alexgaoth/awesome-reverse-engineered》 仓库的核心理念。它收录了 17,728 个通过逆向闭源应用、API、设备、协议、文件格式、游戏和 AI 产品而构建的开源项目，累计获得 1230 万 GitHub 星标，堪称逆向工程领域的“总目录”。

一、 一个仓库，解决“重复造轮子”的痛点

这个仓库的定位非常清晰：在你动手逆向任何东西之前，先来这里搜一搜。正如仓库首页所写，即便有了 REA、Ghidra 这类让逆向越来越快的工具，你要打开的那个应用、API 或文件格式，很可能早已有人做过，只是那个仓库藏在某个没人链接的角落。这个索引就是把这些散落的成果汇聚起来，让你从别人停下的地方开始，而不是从零开始。

从数据上看，它的覆盖面相当可观：在 17,728 个项目中，10,115 个处于活跃状态，2,493 个节奏放缓，3,489 个休眠，1,176 个已被作者归档。语言分布上，Python 以 4,026 个项目居首，C++（2,663）、C（2,535）、JavaScript（1,060）和 C#（958）紧随其后。这些数字背后，是大量原本可能被重复劳动消耗掉的时间。

仓库按类别组织项目，每个类别都配有代表性项目。几个值得注意的类别包括：

## 主要类别代表项目

《游戏反编译与重实现》是最大的类别，收录 6,106 个项目，代表作有 PS4 模拟器 shadPS4、x86 模拟器 v86 和 PS3 模拟器 RPCS3。设备、IoT 与硬件类别有 3,121 个项目，包括电子书阅读器 KOReader、让 AirPods 在安卓上更好用的 LibrePods，以及罗技设备的开源驱动 OpenLogi。非官方 Web/App API 客户端收录 989 个项目，yt-dlp 和 youtube-dl 是其中的常青树，MediaCrawler 则专注于小红书、抖音、快手、B 站和微博的内容抓取。

值得一提的是 《AI 工具与 LLM 客户端》类别，755 个项目中包括 claw-code（Claude Code 源码泄露后的净室重写）、system-prompts-and-models-of-ai-tools（提取自 Cursor、Claude Code、Devin 等工具的系统提示词）和 system_prompts_leaks（ChatGPT、Claude、Gemini 等厂商系统提示词的历史存档）。《中文与亚洲平台》类别有 778 个项目，lx-music-desktop、alist 和 RevokeMsgPatcher（阻止微信、QQ、TIM 消息撤回的二进制补丁工具）都是国内用户熟悉的面孔。

## 产品复活案例

《Spotify Car Thing》 是 Spotify 在 2024 年停产的车载播放器，开源项目 《DeskThing》 通过逆向让其继续可用。《Nest 学习型恒温器（第一、二代）》在 2025 年被 Google 终止支持，NoLongerEvil Thermostat 项目让它重获新生。《Pebble 智能手表》在 2018 年被 Fitbit 收购后停止服务，社区通过 mobile-app 项目维持其功能。《Neato 扫地机器人》在 2025 年厂商退出后，fang 项目接管了控制权。还有 AOL Instant Messenger 和 ICQ 这两个即时通讯时代的化石，都通过 Open OSCAR Server 得以复活。

这些案例说明，逆向工程的价值不止于“破解”，更在于互操作性与数字保存——当厂商放弃一个产品时，用户和社区有权通过逆向继续使用自己购买的设备和服务。

四、 给 AI Agent 用的索引：不止是给人看的

## AI Agent接入方式

这个仓库的另一个亮点是它对 AI 时代的适配。除了网页搜索，它还提供了多种让 AI Agent 直接调用索引的方式：通过 npx skills add 安装 Agent Skill，通过 /plugin install 安装 Claude Code 插件，或者配置 MCP 服务器让 Claude Desktop、Cursor 等客户端直接查询。仓库甚至提供了一个仅依赖 Python 标准库的单文件脚本，可以在任意 shell 中运行：

python3 re_index.py search tuya local # 按关键词排序匹配

python3 re_index.py info make-all/tuya-local # 查看条目和 README 摘要

python3 re_index.py clone make-all/tuya-local # 浅克隆到 vendor/ 目录

这意味着当你的 AI 助手需要和一个没有官方 API 的智能插座、汽车或聊天应用打交道时，它可以自动搜索这个索引，按星标、活跃度和许可证排序，阅读 README，然后选出合适的工具。仓库还标注了每个项目的健康状态：🟢 表示过去 12 个月有推送，🟡 表示 1 到 3 年前，🔴 表示超过 3 年休眠，🗄️ 表示已被归档。这一点很实用，因为非官方 API 随时可能因厂商改动而失效，依赖之前先看健康度是明智之举。

五、 边界与筛选：什么收，什么不收

## 收录范围与排除项

仓库的收录范围有明确界定：《互操作性、保存和研究》类项目——非官方客户端和 SDK、开源驱动、本地控制库、文件格式解析器、协议文档、重实现和反编译。仓库明确排除了漏洞利用、越狱、证书绑定绕过、解密工具、作弊器、DRM 或付费墙移除、验证码破解、账号机器人和凭据工具。筛选过程中有 202 个仓库因超出范围被丢弃。

这一边界并非随意划定。仓库提到，为互操作性进行的逆向工程在许多地方受到法律保护，例如美国版权法 17 U.S.C. §1201(f) 和欧盟软件指令第 6 条。同时它也提醒使用者：使用非官方客户端可能违反服务条款，应仅用于自己的账号、设备和数据。

六、 结语

awesome-reverse-engineered 的价值，不在于它收录了多少个项目——尽管 17,728 这个数字本身已经足够惊人——而在于它传递的一种工作伦理：“逆向工程是社区的知识积累，而不是个人的重复劳动”。你花时间逆向出来的东西，开源出来，加进这个索引，下一个人就能从你停下的地方开始。
