
# 恶意木马分析报告：假冒"手机OA"应用

---

## 一、概述

2026年7月，智联招聘平台出现一起钓鱼攻击事件：一名假冒HR通过招聘聊天向求职者发送名为"手机OA"的APK文件，实际上是一个重新打包的 Telegram 客户端远程访问木马（RAT）。受害者安装后，所有通信数据将被发送至攻击者自建的私有 Telegram 服务器。

## 五、远控能力分析

### 5.1 命令执行（Shell）

该木马集成了 `com.blankj.utilcode.util.ShellUtils` 工具库，具备完整的 Shell 命令执行能力：

- `ShellUtils.execCmd(List<String>, boolean)` — 同步执行
- `ShellUtils.execCmd(List<String>, boolean, boolean)` — 同步执行（含 root 参数）
- `ShellUtils.execCmdAsync(List<String>, boolean, Callback)` — 异步执行（带回调）
- `ShellUtils.execCmdAsync(List<String>, boolean, boolean, Callback)` — 异步执行（含 root）

攻击者通过 Telegram 消息通道下发命令字符串，由 ShellUtils 在受害者设备上执行，可实现：

- 读写任意文件
- 安装 / 卸载应用
- 执行任意系统命令
- Root 权限操作（如果设备已 root）

### 5.2 文件下发

| 机制 | 说明 |
|---|---|
| Telegram 文件传输 | 通过私有 Telegram 服务器下发任意类型文件（.apk / .dex / .jar 等） |
| 远程更新 | 可下发新版木马 APK 实现自身更新 |
| 配置文件 | 可动态修改 C2 地址、代理配置等 |

### 5.3 数据窃取

利用 Telegram 客户端的完整功能 + 已获取的权限，可窃取：

- 通讯录全部数据
- 短信和彩信内容
- 通话记录
- 实时位置
- 摄像头拍摄和麦克风录音
- 手机识别码（IMEI）和电话号码
- 日历事件
- 已安装应用列表

### 5.4 无障碍权限

**未发现无障碍服务相关模块**：无 `BIND_ACCESSIBILITY_SERVICE` 权限声明，无自定义 `AccessibilityService` 子类，无自动点击或模拟手势代码。该木马的远控完全依赖 Shell 命令执行和 Telegram 消息通道。

该木马采用**多层保活策略**确保长期在线：

| 层级 | 机制 | 说明 |

## 十、防御与处置建议

### 10.1 立即处置

1. **卸载应用**：从受害者设备卸载包名 `fi.yubrgsmmad.evyccjvmq` 的应用
2. **修改密码**：重置所有可能被窃取的账户密码（Telegram、邮箱、银行等）
3. **清除数据**：清除应用残留的 `/data/data/fi.yubrgsmmad.evyccjvmq/` 目录

### 10.2 网络封堵

在防火墙 / DNS / WAF 层面封禁以下域名和 IP：

```
m12345.cc
m12345.com
www.shareinstall.com.cn
```

### 10.3 终端检测

- 部署 EDR/杀毒软件，添加上述 SHA256 和包名的检测规则
- 监控 `ShellUtils.execCmd` 和 `Runtime.exec()` 的调用
- 监控对 `libuuKuDmlBszqh.so` 和 `libuuKuDmlBszqhloc.so` 的加载

### 10.4 员工培训

- 提醒求职者：正规企业不会通过招聘平台直接发送 APK 安装文件
- 所有公司内部 OA 应用应通过官方应用商店或企业官网下载
- 对于以 `.apk` 格式分发的"办公应用"保持高度警惕
