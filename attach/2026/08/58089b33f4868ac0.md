**样本：** `gnuxgk.apk`  
**分析日期：** 2026-08-20  
**分析方法：** GDA 静态逆向（未加壳 DEX 反编译）  
**结论：** 伪装成 kiosk / MDM 的 **BTMob 远控木马（Banking Trojan + RAT）**，版本 `BTMob-Agent/1.2.0`。具备屏幕/摄像头/麦克风实时流、无障碍远程操控、HTML Overlay 钓鱼、短信/通讯录/键盘记录窃取、锁机与清空锁屏密码等能力。

## 1. 执行摘要

该 APK 包名为 `com.example.kiosk`，对外文案是 “MDM remote management and kiosk enforcement”，实际品牌串、User-Agent、默认 C2 均指向 **BTMob RAT** 家族。

核心链路：

1. 安装后以向导诱导开启无障碍、通知监听、电池优化、设备管理员等。
2. 用 `registrationSecret` / `pairingToken` 向 C2 注册，拿到 `device_id` + `device_token`。
3. 前台服务以约 **280ms** 间隔轮询 `device/{id}/commands/pending`。
4. 命令由 `CommandHandler`（混淆类 `X5`）分发；需要手势/覆盖层的交给无障碍服务执行。
5. 屏幕、摄像头、麦克风通过 **WebSocket** 实时回传；短信、通讯录、键盘、钓鱼表单走 REST 上报。

**判定：恶意远控。** 不是合法 MDM。建议隔离取证，不要在个人设备上安装运行。

## 5. 运行逻辑

### 5.1 启动

`KioskApplication.onCreate()`：

1. `AppGuard.check()`：反调试、可选签名校验。
2. `Kh.II()`：初始化加密 / 备份 SharedPreferences。
3. 初始化 Room `kiosk_commands.db`。
4. `AgentHealth.init()`。
5. 设置未捕获异常处理器。
6. 若已配对（同时存在 `device_id` 与 `device_token`）：
   - 初始化 Retrofit C2（`Er.O(serverUrl, token)`）
   - 启动 Job / WorkManager / 前台服务 / Watchdog

无障碍 `onServiceConnected()` 后再次拉起前台服务，并广播 `com.example.kiosk.A11Y_CONNECTED`。

### 5.2 权限诱导向导

`MainActivity` 用枚举 `Aj` 分阶段强制授权，全部完成后才加载 WebView（默认 `https://www.btmobrat.net/`）：

```
WAIT_A11Y → RUNTIME → STORAGE → BATTERY → OEM_AUTOSTART
→ NOTIFICATIONS → USAGE → NOTIF_LISTENER → DRAW_OVER → HIDE_ICON → DONE
```

`PermissionRequestActivity` 会尝试 `requestDismissKeyguard`（锁屏上也弹权限框）。若 `auto_grant=true` 且无障碍已连接，则调用 `KioskAccessibilityService.IO()` 自动点击系统「允许」按钮。

### 5.3 命令主循环

`KioskForegroundService` 协程：

1. 读取 `poll_interval_ms`，**默认 280ms**。
2. 持有 WakeLock `kiosk:polling` 与 WifiLock `kiosk:wifi`。
3. `GET device/{id}/commands/pending`。
4. 写入 Room，状态 `PENDING → RUNNING`。
5. 一部分命令在前台服务内执行；其余广播 `com.example.kiosk.EXECUTE_COMMAND`（extra `local_id`）给无障碍。
6. `POST device/{id}/commands/{cmdId}/ack`。
7. `POST device/{id}/status` 心跳。

无障碍未绑定时回执 `A11Y_OFF` / `A11Y_UNBOUND`，`readyState=limited`。

## 8. 关键恶意行为详解

### 8.1 HTML Overlay 钓鱼

1. C2 下发 `SHOW_HTML_OVERLAY`，`html` 为完整钓鱼页。
2. 无障碍通过 `WindowManager` 盖全屏 WebView：
   - 有悬浮窗权限 → `TYPE_APPLICATION_OVERLAY`
   - 否则 → **无障碍 Overlay**（不依赖 `SYSTEM_ALERT_WINDOW`）
3. 注入 JS 桥 `vh`：`returnResult` / `sendResult` / `submit` / `postMessage` / `close` / `hide`。
4. 内置脚本会：
   - 劫持 `window.Android`，保存真实 Java 桥为 `__btmobNative`
   - 拦截 form submit 与登录按钮（多语言：login / sign in / entrar / zaloguj 等）
   - wrap `send_form` / `doLogin` / `login`
   - 8 秒去重后把 input/select/textarea 值回传 native
5. `KioskAccessibilityService.IlO()` 清洗 JSON，写入 `files/overlay_results_queue.json`（最多 200 条）。
6. 后台线程 `overlay-result` 调用 `pushOverlayResult`：

```json
{
  "data": { "...表单字段..." },
  "package": "目标包名",
  "source": "html_overlay",
  "capturedAt": "ISO-8601"
}
```

这是典型的银行 / 钱包 / 邮箱覆盖层。

### 8.2 键盘记录

`onKeyEvent`：将按键转为字符（含退格、回车、空格、Tab），并附带：

- 当前包名
- `viewId`
- hint
- 是否 `isPassword`

`TYPE_VIEW_TEXT_CHANGED` 对可编辑 / 密码框再采集一次。切换应用会清空缓冲。数据走 `device/{id}/keylog`。

### 8.3 通知与短信

- `KioskNotificationListener.onNotificationPosted`：抽取 title / text / bigText / messages。
- 无障碍 `TYPE_NOTIFICATION_STATE_CHANGED` 为第二路。
- `GET_SMS` 直接查短信 ContentProvider，inbox / sent 各取 `limit/2` 条，按 `date DESC`。

### 8.4 静默音视频

`CameraStartActivity` / `MicStartActivity`：

- 透明主题、`excludeFromRecents`、`noHistory`
- 独立 affinity：`com.example.kiosk.silent.camera` / `silent.mic`
- `showWhenLocked=false`、`turnScreenOn=false`（锁屏也不亮屏）

### 8.5 锁机与阻断

`KioskLockActivity.dispatchKeyEvent` 直接吞掉：

- Home (3)、Back (4)、Power (26)、Menu (82)、Search (84)、App-switch (187)

`onBackPressed()` 为空。触摸阻断层文案写明：本地滑动失效，远程控制仍可用。

### 8.6 隐身与防卸载

- `HIDE_ICON`：`PackageManager.setComponentEnabledSetting(MainLauncher, DISABLED)`
- `PREVENT_UNINSTALL`：无障碍识别系统卸载界面并点返回 / Home；设备管理员提供更强保护
- 识别 `systemui` recents 并关闭，降低用户清理机会

## 12. 处置建议

1. **不要在个人真机安装。** 分析请用隔离虚拟机 / 专用取样机，断网或仅导向蜜罐。
2. 已安装设备：
   - 先断网。
   - 安全模式尝试卸载；若被设备管理员锁住，先撤销「设备管理应用」，必要时恢复出厂。
   - 视为短信验证码、通知、锁屏密码、已打开过的银行/钱包账号均可能泄露。
   - 轮换密码与 2FA，通知银行冻结异常会话。
3. 网络侧：拦截 `btmobweb.com`、`btmobrat.net`，关注 UA `BTMob-Agent/` 与路径 `/device/*/commands/pending`、`/screen?role=device`。
4. 主机侧：查包名 `com.example.kiosk`、无障碍列表、通知使用权、设备管理员、桌面是否无图标但进程仍在。
